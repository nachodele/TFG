# Problema: Pertenencia de Cadenas a un Lenguaje

## Enunciado:
¿Las cadenas aabbbbbba y aabbbbba pertenecen a {a, ab, bb}* ?
a) Sí, ambas
b) Sólo la primera
c) Sólo la segunda
d) Ninguna de las dos

## Solución:
La respuesta correcta es a) Sí, ambas.

### Justificación:

1. Para la cadena aabbbbbba:
   - Se puede descomponer como: a-a-bb-bb-bb-a
   - Cada componente pertenece al conjunto {a, ab, bb}:
     - 'a' aparece al principio (dos veces) y al final
     - 'bb' aparece tres veces en el medio

2. Para la cadena aabbbbba:
   - Se puede descomponer como: a-ab-bb-bb-a
   - Cada componente pertenece al conjunto {a, ab, bb}:
     - 'a' aparece al principio y al final
     - 'ab' aparece una vez
     - 'bb' aparece dos veces

3. El asterisco (*) en {a, ab, bb}* indica la clausura de Kleene, lo que significa que se pueden concatenar cero o más elementos del conjunto en cualquier orden.

4. Ambas descomposiciones muestran que las cadenas se pueden formar utilizando únicamente elementos del conjunto {a, ab, bb}, concatenados en un orden específico.

## Conclusión:
Ambas cadenas, aabbbbbba y aabbbbba, pertenecen al lenguaje definido por {a, ab, bb}*, ya que se pueden construir utilizando únicamente los elementos del conjunto dados, concatenados de manera válida según la definición de la clausura de Kleene.
