# Problema: Estudio de un lenguaje.

## Enunciado:  
El lenguaje L = {x^n y^m | n + m < 1000 y |n - m| < 3}, ¿es regular? 
a) Sí  
b) No  

## Solución:  
La afirmación correcta es a) Sí.  

### Justificación:  
1. Lenguaje finito:  
   -  L  está restringido por dos condiciones:  
     1.  n + m < 1000 : Limita la longitud máxima de las cadenas a 999 caracteres.  
     2.  |n - m| < 3 : Restringe la diferencia entre  n  y  m  a valores pequeños ≤ 2.  
   - Estas condiciones definen un número finito de combinaciones válidas.  

2. Cálculo de cardinalidad:  
   - Caso 1:  n = m : Hay 500 cadenas ( n  puede variar de 0 a 499, ya que  2n < 1000 ).  
   - Caso 2:  n = m + 1  o  m = n + 1 : Cada caso aporta 500 cadenas ( n  de 0 a 499).  
   - Caso 3:  n = m + 2  o  m = n + 2 : Cada caso aporta 499 cadenas ( n  de 0 a 498).  
   - Total:  500 + 500 + 500 + 499 + 499 = 2498  cadenas.  

3. Propiedad fundamental:  
   - Todo lenguaje finito es regular.  
   - Un autómata finito determinista (AFD) puede construirse enumerando explícitamente todas las cadenas válidas y aceptándolas mediante estados finales dedicados.  

### Conclusión:  
Al ser  L  un lenguaje finito con un número acotado de cadenas ( 2498 ), se concluye que  L  es regular. La respuesta correcta es a) Sí.
