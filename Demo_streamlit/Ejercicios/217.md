# Problema: Simulación de un AFD para las cadenas dadas.  

## Enunciado:  
Compruébese si el autómata finito determinista (AFD) reconoce las cadenas x = aabcaca, y = acababa, y z = baaabacc, mostrando las transiciones que se van produciendo paso a paso.  

## Solución:  

### Tabla de transiciones del AFD:  
El autómata tiene la siguiente tabla de transiciones:  

| Estado | Entrada 'a' | Entrada 'b' | Entrada 'c' |  
|--------|-------------|-------------|-------------|  
| q0     | q1          | q1          | q3          |  
| q1     | q1          | q2          | q4          |  
| q2     | q2          | q4          | q4          |  
| q3     | q2          | q4          | q4          |  
| q4     | q0          | q0          | q3          |  

### Simulación paso a paso para cada cadena:  

#### 1. Cadena x = aabcaca:  
Transiciones realizadas:  
- (q0, '') -> (q1, 'a') -> (q1, 'a') -> (q2, 'b') -> (q4, 'c') -> (q0, 'a') -> (q3, 'c') -> (q2, 'a').  

Estado final alcanzado: **q2**.  
Resultado: **No reconocida** (el estado final no es un estado de aceptación).  

#### 2. Cadena y = acababa:  
Transiciones realizadas:  
- (q0, '') -> (q1, 'a') -> (q4, 'c') -> (q0, 'a') -> (q1, 'b') -> (q1, 'a') -> (q2, 'b') -> (q2, 'a').  

Estado final alcanzado: **q2**.  
Resultado: **No reconocida** (el estado final no es un estado de aceptación).  

#### 3. Cadena z = baaabacc:  
Transiciones realizadas:  
- (q0, '') -> (q1, 'b') -> (q1, 'a') -> (q1, 'a') -> (q1, 'a') -> (q2, 'b') -> (q2, 'a') -> (q4, 'c') -> (q3, 'c').  

Estado final alcanzado: **q3**.  
Resultado: **Reconocida** (el estado final es un estado de aceptación).  

## Conclusión:  
- La cadena x = aabcaca: **Rechazada**.  
- La cadena y = acababa: **Rechazada**.  
- La cadena z = baaabacc: **Aceptada**.
