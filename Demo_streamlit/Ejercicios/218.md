# Problema: Simulación de un AFD para las cadenas dadas.  

## Enunciado:  
Compruébese si reconocen o no las cadenas que se indican en cada caso, mostrando las transiciones que se van produciendo paso a paso.  

### Tabla de transiciones del AFD:  

| Estado | Entrada 'd' | Entrada '0' | Entrada 'p' |  
|--------|-------------|-------------|-------------|  
| q0     | q1          | q2          | -           |  
| q1     | q1          | q1          | q3          |  
| q2     | -           | -           | q3          |  
| q3     | q4          | q5          | -           |  
| q4     | q4          | q6          | -           |  
| q5     | q4          | q6          | -           |  
| q6     | q4          | q6          | -           |

Donde:  
- d ∈ 1, 2, 3, 4, 5, 6, 7, 8, 9 representa los dígitos distintos de cero.  
- 0 es el dígito cero.  
- p es el punto decimal ".".  

Las cadenas a analizar son:  
- u = 0.70089  
- v = 012.0  
- w = 12.0  
- x = 10203  
- y = 45.060900  
- z = 0.0  

---

### Simulación paso a paso para cada cadena:  

#### 1. Cadena u = 0.70089:  
Transiciones realizadas:  
- (q_0, '0') → (q_2, '.') → (q_3, '7') → (q_4, '0') → (q_6, '0') → (q_6, '8') → (q_4, '9').  

Estado final alcanzado: q_4.  
Resultado: Reconocida (el estado final es un estado de aceptación).  

#### 2. Cadena v = 012.0:  
Transiciones realizadas:  
- (q_0, '0') → (q_2, '1'): No hay transición válida desde q_2 con el símbolo '1'.  

Resultado: No reconocida (la cadena no puede completarse).  

#### 3. Cadena w = 12.0:  
Transiciones realizadas:  
- (q_0, '1') → (q_1, '2') → (q_1, '.') → (q_3, '0').  

Estado final alcanzado: q_5.  
Resultado: Reconocida (el estado final es un estado de aceptación).  

#### 4. Cadena x = 10203:  
Transiciones realizadas:  
- (q_0, '1') → (q_1, '0') → (q_1, '2') → (q_1, '0') → (q_1, '3').  

Estado final alcanzado: q_1.  
Resultado: Reconocida (el estado final es un estado de aceptación).  

#### 5. Cadena y = 45.060900:  
Transiciones realizadas:  
- (q_0, '4') → (q_1, '5') → (q_1, '.') → (q_3, '0') → (q_5, '6') → (q_4, '0') → (q_6, '9') → (q_4, '0') → (q_6).  

Estado final alcanzado: q_6.

#### 6. Cadena z = 0.0:
