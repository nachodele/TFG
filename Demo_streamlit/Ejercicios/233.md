# Problema: Regularidad de un Lenguaje.

## Enunciado:  
El lenguaje (xyz)^n ∣ n ≥ 0 es:  
a) Regular  
b) Independiente de contexto, no regular  

## Solución:  
La respuesta correcta es **a) Regular**.  

### Justificación:  

1. **Propiedad del lenguaje**:  
   - El lenguaje (xyz)^n ∣ n ≥ 0 está formado por cadenas que consisten en cero o más repeticiones de la subcadena "xyz".  
   - Este patrón puede describirse mediante la expresión regular (xyz)^*, lo cual indica que el lenguaje es regular.  

2. **Construcción de un autómata finito**:  
   - Es posible construir un autómata finito determinista (AFD) que reconozca este lenguaje.  
   - El autómata tendría estados que verifican la aparición secuencial de los símbolos 'x', 'y', y 'z' en cada repetición del patrón "xyz".  

3. **Construcción de una gramática regular**:  
   - También se puede definir una gramática regular para este lenguaje, como la siguiente:  
     - S → xM  
     - M → yN  
     - N → zS  
     - S → λ  

4. **Conclusión**:  
   - Dado que el lenguaje puede ser descrito mediante una expresión regular, un autómata finito o una gramática regular, se concluye que es un lenguaje regular.  

**Respuesta correcta: a) Regular**.
