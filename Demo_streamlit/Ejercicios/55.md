# Problema: Algoritmo para convertir una gramática lineal por la izquierda (GLI) en una gramática lineal por la derecha (GLD).

## Enunciado
Encuentre un algoritmo capaz de convertir una gramática lineal por la izquierda (GLI) en una gramática lineal por la derecha (GLD).

## Solución

### Definición Formal
Sea G = (ΣN, ΣT, S, P) una gramática lineal por la izquierda, donde:

- ΣN es el conjunto de símbolos no terminales
- ΣT es el conjunto de símbolos terminales
- S es el símbolo inicial
- P es el conjunto de producciones de la forma A → Bα o A → α

El siguiente algoritmo genera una gramática G' = (ΣN', ΣT, S', P') lineal por la derecha equivalente a G.

### Algoritmo GLI → GLD
#### Paso 1: Eliminar "axioma inducido"
Este paso se refiere a eliminar situaciones donde el símbolo inicial aparece en la parte izquierda de una producción.

Para cada producción p∈P que contenga al axioma inducido (reglas A → Sα):

- Crear un nuevo no terminal S': ΣN' = ΣN ∪ {S'}
- Para cada producción S → β en P:
- Crear nueva producción p' = S' → β, P' = P' ∪ {p'}
- Transformar A → Sα por A → S'α, P' = P' ∪ {p'} \ {p}

#### Paso 2: Crear grafo dirigido G
1. Para cada A∈ΣN: Crear un nodo A
2. Para cada producción A → Bα en P:

Crear un arco B --α--> A
3. Para cada producción A → α (donde α no contiene no terminales):

Crear un arco λ --α--> A
4. Si existe la regla S → λ:

Crear un arco sin etiqueta λ --> S

#### Paso 3: Crear otro grafo dirigido G' a partir de G
1. Intercambiar nombres a los nodos S y λ
2. Invertir el sentido de todos los arcos

#### Paso 4: Construir conjunto de reglas
1. Para cada nodo A (excepto λ): Agregar A∈ΣN'
2. Para cada arco A --a--> B:

Crear producción p: A → aB
3. Para cada arco A --a--> λ:

Crear producción p: A → a
4. Si existe arco S ---> λ (sin etiqueta):

Crear producción p: S → λ
