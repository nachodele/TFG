# Problema: Determinar si la cadena "bab" pertenece a  L(G)  usando CYK

## Enunciado  
Dada la gramática  G = (a, b, S, A, B, C, X, S, P) , donde:  
 P =   
 S → AB ∣ XC   
 A → BA ∣ a   
 B → CC ∣ b   
 C → AB ∣ a   
 X → b   

Determine, aplicando el algoritmo CYK, si la cadena  x = bab  pertenece a  L(G) .  

## Solución

### Paso 1: Verificación de la Forma Normal de Chomsky (FNC)  
La gramática ya está en FNC después de corregir  S → bC :  
-  S → XC  (introduciendo  X → b )  
- Todas las reglas cumplen  A → BC  o  A → a .  

### Paso 2: Inicialización de la tabla CYK  
Cadena:  bab  (longitud  n = 3 ).  

#### Subcadenas de longitud 1:  
| Posición | Carácter | No terminales |  
|----------|----------|---------------|  
| 1        | b        |  B, X     |  
| 2        | a        |  A, C     |  
| 3        | b        |  B, X     |  

Tabla inicial:  
- Fila 1:  B, X, A, C, B, X   
- Fila 2:  ∅, ∅   
- Fila 3:  ∅   

### Paso 3: Subcadenas de longitud 2  

1. Subcadena [1,2] ("ba"):  
   - Combinaciones:  
     -  B  (pos1) +  A  (pos2) →  A → BA  →  A   
     -  B  (pos1) +  C  (pos2) → Sin reglas  
     -  X  (pos1) +  A/C  (pos2) → Sin reglas  
   - Resultado:  A   

2. Subcadena [2,3] ("ab"):  
   - Combinaciones:  
     -  A  (pos2) +  B  (pos3) →  S → AB  →  S   
     -  C  (pos2) +  B  (pos3) →  C → AB  →  C   
   - Resultado:  S, C   

Tabla actualizada:  
- Fila 1:  B, X, A, C, B, X   
- Fila 2:  A, S, C   
- Fila 3:  ∅   
### Paso 4: Subcadena de longitud 3 ("bab")  

1. Combinaciones:  
   -  B, X  (pos1) +  S, C  (pos2-3):  
     -  B  +  S  → Buscar  ? → BS  → No existe  
     -  B  +  C  →  C → BC  → No existe  
     -  X  +  S/C  → Sin reglas  

   -  A  (pos1-2) +  B, X  (pos3):  
     -  A  +  B  →  S → AB  →  S   
     -  A  +  X  → Sin reglas  

Resultado final:  
- Fila 3:  S  

### Conclusión  
El símbolo inicial  S  está presente en la celda correspondiente a la cadena completa ([1,3]).  

Respuesta:  
La cadena  x = bab  sí pertenece a  L(G) .
