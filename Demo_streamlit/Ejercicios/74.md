# Problema: Determinar si una cadena pertenece al lenguaje generado por la gramática  G  utilizando el algoritmo CYK

## Enunciado
Dada la gramática  G = (a, b, S, A, B, C, S, P) , donde:

P = 
S → AB | BC, 
A → BA | a, 
B → CC | b, 
C → AB | a


Determine, aplicando el algoritmo CYK, si la cadena x = bab pertenece al lenguaje  L(G) .

---

## Solución

### Paso 1: Inicialización del algoritmo CYK
La cadena  x = bab  tiene longitud  n = 3 . Construimos una tabla triangular de dimensiones  3 x 3 , donde cada celda contiene los no terminales que generan las subcadenas correspondientes.

#### Subcadenas de longitud 1:
Para cada símbolo terminal en la cadena, identificamos los no terminales que lo generan:

| Posición | Carácter | No terminales generadores |
|----------|----------|----------------------------|
| 1        |  b   |  B  (por  B → b ) |
| 2        |  a   |  A, C  (por  A → a, C → a ) |
| 3        |  b   |  B  (por  B → b ) |

---

### Paso 2: Subcadenas de longitud mayor a 1

#### Subcadenas de longitud 2:
Para cada subcadena de longitud 2, combinamos los resultados de las subcadenas más pequeñas.

1. **Subcadena [1,2] ("ba"):**
   - Combinaciones posibles:  
     - Primera parte ( b = B ), segunda parte ( a = A, C ).
   - Reglas aplicables:
     -  A → BA : Si  B  y  A  están presentes.
     - Resultado:  A .

2. **Subcadena [2,3] ("ab"):**
   - Combinaciones posibles:  
     - Primera parte ( a = A, C ), segunda parte ( b = B ).
   - Reglas aplicables:
     -  S → AB, C → AB : Si  A/C  y  B  están presentes.
     - Resultado:  S, C .

---

#### Subcadenas de longitud 3:
Para la cadena completa ("bab"), combinamos los resultados de las subcadenas más pequeñas.

1. **Subcadena [1,3] ("bab"):**
   - Combinaciones posibles:
     - Primera parte ( b = B ), segunda parte ( ab = S, C ).
   - Reglas aplicables:
     -  S → BC, C → AB : Si  B/S/C  están presentes.
     - Resultado:  S, C .

---

### Paso 3: Tabla CYK completa
La tabla CYK es:

| Longitud | Subcadena | No terminales generados |
|----------|-----------|--------------------------|
| 1        | "b"       | {B}                     |
|          | "a"       | {A, C}                  |
|          | "b"       | {B}                     |
| 2        | "ba"      | {A}                     |
|          | "ab"      | {S, C}                  |
| 3        | "bab"     | {S, C}                  |

---

### Conclusión
El símbolo inicial ( S ) **aparece** en la celda correspondiente a toda la cadena ( [1,3] = "bab" ). Por lo tanto:

**Respuesta:**  
**Sí**, la cadena  x = bab  **pertenece** al lenguaje generado por la gramática  G .
