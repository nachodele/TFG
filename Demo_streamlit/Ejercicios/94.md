# Problema: Elementos en un lenguaje

## Enunciado:
Se supone que  L = λ, a . Obtener  L^n  para  n = 0, 1, 2, 3 . ¿Cuántos elementos tiene  L^n  para un  n  arbitrario?

## Solución:
### Definiciones previas
1. Potencia de un lenguaje ( L^n ): Es el conjunto de todas las cadenas obtenidas concatenando exactamente  n  palabras del lenguaje  L . Formalmente:
   -  L^0 = λ , donde  λ  es la palabra vacía.
   -  L^n = L^{n-1} · L, n > 0 , donde "·" denota la concatenación.

2. Cardinalidad de  L^n : Si el lenguaje  L  tiene  |L| = k  elementos, entonces el número de elementos de  L^n  es:
    
   |L^n| = k^n
    
   Para  n = 0 , el único elemento es la palabra vacía, por lo que  |L^0| = 1 .

### Cálculo de  L^n 
Dado que  L = λ, a , tenemos que  |L| = 2 . A continuación, calculamos  L^n  para los valores indicados:

1.  n = 0 :
   - Por definición,  L^0 = λ .
   - Cardinalidad:  |L^0| = 1 .

2.  n = 1 :
   - Por definición,  L^1 = L = λ, a .
   - Cardinalidad:  |L^1| = 2^1 = 2 .

3.  n = 2 :
   - Concatenamos cada elemento de  L  consigo mismo:  
      L^2 = λ·λ, λ·a, a·λ, a·a = λ, a, a, aa = λ, a, aa.
   - Cardinalidad:  |L^2| = 2^2 = 4. 

4.  n = 3 :
   - Concatenamos cada elemento de  L^2  con cada elemento de  L :  
      L^3 = λ·λ·λ, λ·λ·a, λ·a·λ, λ·a·a, a·λ·λ, a·λ·a, a·a·λ, a·a·a. 
     Simplificando:  
      L^3 = λ, a, aa, aaa. 
   - Cardinalidad:  |L^3| = 2^3 = 8. 

### Generalización para un  n  arbitrario
El número de elementos en  L^n  se calcula como:
|L^n| =  
1, si n = 0;  
2^n, si n > 0.

### Resultados finales
- Para los valores dados:
  -  L^0 = λ, |L^0| = 1. 
  -  L^1 = λ, a, |L^1| = 2. 
  -  L^2 = λ, a, aa, |L^2| = 4. 
  -  L^3 = λ, a, aa, aaa, |L^3| = 8. 
- Para un valor arbitrario de  n > 0: |L^n| = 2^n. \
