# Problema: Operaciones sobre lenguajes

## Enunciado:
Si A y B_i son lenguajes sobre Σ para i = 1, 2, 3, ..., probar que:

A · ⋃_{i=1}^{∞} B_i = ⋃_{i=1}^{∞} (A · B_i)

## Solución:
### Paso 1: Definición de la operación de concatenación
La concatenación de dos lenguajes X y Y, denotada como X · Y, se define como:

X · Y = { xy ∣ x ∈ X, y ∈ Y }.

Esto significa que todo elemento del lenguaje resultante es una cadena formada por la concatenación de una cadena de X con una cadena de Y.

### Paso 2: Interpretación del lado izquierdo
El lado izquierdo de la igualdad es:

A · ⋃_{i=1}^{∞} B_i.

Por definición de concatenación, esto equivale a:

A · ⋃_{i=1}^{∞} B_i = { a · b ∣ a ∈ A, b ∈ ⋃_{i=1}^{∞} B_i }.

Dado que b ∈ ⋃_{i=1}^{∞} B_i, por definición de unión infinita, existe un índice i tal que b ∈ B_i. Por lo tanto:

A · ⋃_{i=1}^{∞} B_i = { a · b ∣ a ∈ A, b ∈ B_i, i = 1, 2, 3, ... }.

### Paso 3: Interpretación del lado derecho
El lado derecho de la igualdad es:

⋃_{i=1}^{∞} (A · B_i).

Por definición de unión infinita y concatenación:

⋃_{i=1}^{∞} (A · B_i) = { w ∣ w ∈ A · B_i, i = 1, 2, 3, ... }.

Además, por definición de concatenación:

w ∈ A · B_i implica w = a · b, donde a ∈ A y b ∈ B_i.

Por lo tanto:

⋃_{i=1}^{∞} (A · B_i) = { a · b ∣ a ∈ A, b ∈ B_i, i = 1, 2, 3, ... }.

### Paso 4: Comparación de ambos lados
Comparando los resultados obtenidos en los pasos anteriores:

- El lado izquierdo genera todas las cadenas a · b donde a ∈ A y b pertenece a algún B_i (i = 1, 2, 3, ...).
- El lado derecho también genera todas las cadenas a · b donde a ∈ A y b ∈ B_i (i = 1, 2, 3, ...).

Por lo tanto:

A · ⋃_{i=1}^{∞} B_i = ⋃_{i=1}^{∞} (A · B_i).

### Conclusión:
Se ha demostrado que la igualdad es válida al verificar que ambos lados generan exactamente el mismo conjunto de cadenas.
