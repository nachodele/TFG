# Problema: Demuestre que N^k es numerable para todo k número natural

## Enunciado
Demuestre que el conjunto \( N^k \), definido como el producto cartesiano de \( k \) copias del conjunto de los números naturales \( N \), es numerable para cualquier número natural \( k \).

## Solución
Para demostrar que \( N^k \) es numerable para todo \( k \), seguiremos un razonamiento inductivo basado en las siguientes ideas:

### Paso 1: Definición de numerabilidad
Un conjunto es numerable si existe una biyección entre dicho conjunto y \( N \). Es decir, si podemos enumerar todos sus elementos de forma que cada uno corresponda a un único número natural.

### Paso 2: Caso base (\( k = 1 \))
Cuando \( k = 1 \), tenemos que \( N^1 = N \). Dado que \( N \) es, por definición, numerable, el caso base se cumple.

### Paso 3: Hipótesis inductiva
Supongamos que \( N^k \) es numerable para algún \( k \geq 1 \). Es decir, existe una biyección entre los elementos de \( N^k \) y los números naturales.

### Paso 4: Paso inductivo (\( k + 1 \))
Queremos demostrar que \( N^{k+1} = N^k \times N \) también es numerable. 

- Por la hipótesis inductiva, sabemos que los elementos de \( N^k \) pueden ser enumerados como \( (a_1, a_2, ..., a_k) \), donde cada tupla corresponde a un número natural único.
- Ahora consideremos el producto cartesiano \( N^k \times N \). Cada elemento de este conjunto tiene la forma \( ((a_1, a_2, ..., a_k), b) \), donde \( b \in N \).
- Podemos definir una función inyectiva y sobreyectiva (es decir, una biyección) entre los elementos de \( ((a_1, a_2, ..., a_k), b) \) y los números naturales utilizando un procedimiento de enumeración en zigzag o diagonalización.

#### Enumeración en zigzag
Enumeramos las tuplas de manera sistemática:
1. Primero consideramos todas las tuplas cuya suma de componentes sea igual a 0 (solo el elemento \( (0, 0, ..., 0) )\).
2. Luego las tuplas cuya suma sea igual a 1 (\( (1, 0, ..., 0), (0, 1, ..., 0), ..., (0, 0, ..., 1) )\).
3. Continuamos con las tuplas cuya suma sea igual a 2, y así sucesivamente.

Este procedimiento garantiza que cada elemento de \( ((a_1, a_2, ..., a_k), b) \) sea asignado a un número natural único.

### Conclusión
Por inducción sobre \( k \), hemos demostrado que para todo número natural \( k \), el conjunto \( N^k \) es numerable.
