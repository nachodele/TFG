# Problema: Estudiar la siguiente afirmación: "Hay tantos números impares como números enteros".

## Enunciado:
Estudie la siguiente afirmación: "Hay tantos números impares como números enteros".

---

## Solución:
### Explicación:
La afirmación "Hay tantos números impares como números enteros" es correcta y se fundamenta en el concepto de correspondencia biyectiva entre conjuntos infinitos.

#### Definición de los conjuntos:
1. El conjunto de los números enteros ( Z ) incluye todos los números enteros positivos, negativos y el cero:
   Z = {..., -3, -2, -1, 0, 1, 2, 3, ...}.

2. El conjunto de los números impares ( I ) incluye todos los enteros que no son divisibles entre 2:
   I = {..., -3, -1, 1, 3, 5, ...}.

Ambos conjuntos son infinitos. Sin embargo, para comparar su cardinalidad (tamaño), debemos establecer una correspondencia uno a uno (biyectiva) entre ellos.

#### Correspondencia biyectiva:
Podemos definir una función f: Z → I que asocia cada número entero con un número impar. Por ejemplo:
f(n) = 2n + 1,
donde n ∈ Z.

Esta función tiene las siguientes propiedades:
- Es inyectiva: Cada número entero n se asocia con un único número impar f(n) = 2n + 1.
- Es suprayectiva: Para cualquier número impar m ∈ I, existe un n = (m - 1)/2 ∈ Z tal que f(n) = m.

Por lo tanto, la función f(n) = 2n + 1 establece una correspondencia uno a uno entre los números enteros y los números impares.

#### Conclusión:
Dado que existe una correspondencia biyectiva entre los números enteros (Z) y los números impares (I), ambos conjuntos tienen la misma cardinalidad. Esto significa que hay tantos números impares como números enteros, es una afirmación verdadera.

### Observaciones adicionales:
Este resultado puede parecer contraintuitivo porque los números impares son un subconjunto de los números enteros. Sin embargo, en teoría de conjuntos infinitos, un conjunto infinito puede tener la misma cardinalidad que uno de sus subconjuntos si se puede establecer una correspondencia biyectiva entre ellos.
