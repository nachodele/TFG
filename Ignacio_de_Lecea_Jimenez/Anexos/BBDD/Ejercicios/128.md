# Problema: Simulación de un AFD para las cadenas dadas.

## Enunciado:
Compruébese si las siguientes cadenas son reconocidas por los autómatas indicados, mostrando las transiciones que se producen paso a paso.

### AFN
#### Tabla de transiciones:
| Estado actual | Entrada | Nuevo estado |
|---------------|---------|--------------|
| 107           |  a  | 108          |
| 108           |  a  | 109          |
| 109           |  c  | 110          |
| 110           |  b  | Aceptación   |

#### Análisis de las cadenas:
1.  w = aacb :
   - Transiciones:  
     - (107, 'a', 108), (108, 'a', 109), (109, 'c', 110), (110, 'b', Aceptación).  
   - Resultado: Aceptada.

2.  x = acabbcc :
   - Transiciones posibles:  
     - (107, 'a', 108), (108, 'c', REJECTED).  
   - Resultado: Rechazada.

3.  y = bbcac :
   - Transiciones posibles:  
     - (107, 'b', REJECTED).  
   - Resultado: Rechazada.

4.  z = accac :
   - Transiciones posibles:  
     - (107, 'a', 108), (108, 'c', REJECTED).  
   - Resultado: Rechazada.
