# Problema: Simulación de un AFD para las cadenas dadas.

## Enunciado:
Compruébese si las siguientes cadenas son reconocidas por los autómatas indicados, mostrando las transiciones que se producen paso a paso.

---

## Solución:
### AFN
#### Tabla de transiciones:
| Estado actual | Entrada | Nuevo estado |
|---------------|---------|--------------|
| 131           |  a  | {q1}         |
| 132           |  b  | {q2, q3}     |
| 133           |  c  | {q3, q4}     |
| 134           |  ε  | {q2}         |
| 135           |  a  | {q1, q2, q3} |
| 136           |  b  | {q3}         |
| 137           |  c  | {q4}         |

#### Análisis de las cadenas:
1.  x = aabc :
   - Transiciones:  
     - (131, 'a', {q1}), (132, 'a', {q2, q3}), (133, 'b', {q3}), (134, 'c', {q4}).  
   - Resultado: Aceptada.

2.  y = bbacab :
   - Transiciones:  
     - (131, 'b', REJECTED).  
   - Resultado: Rechazada.

3.  z = bacaabc :
   - Transiciones:  
     - (131, 'b', REJECTED).  
   - Resultado: Rechazada.
