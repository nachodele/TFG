# Problema: Verificar si la gramática genera el lenguaje dado

## Enunciado
Sea L el lenguaje x^m y^n tal que n ≤ m ≤ 2n. Determine si la siguiente gramática es correcta para generar L:

### Gramática propuesta:
- S → X 
- X → Y 
- X → xXy 
- Y → xxYy
- X → λ 
- Y → λ 

Opciones:  
a) Correcta.  
b) Incorrecta.

Solución: a) Correcta.

## Solución

### Paso 1: Análisis de las reglas de producción
La gramática propuesta tiene las siguientes características:
1. El símbolo inicial es  S , que deriva directamente en  X .
2. Las reglas para  X :
   -  X → xXy : Añade un par de símbolos terminales ( x, y), manteniendo la estructura recursiva.
   -  X → Y : Permite pasar al no terminal  Y  para continuar la derivación.
   -  X → λ : Finaliza la derivación desde  X .
3. Las reglas para  Y :
   -  Y → xxYy : Añade dos símbolos terminales ( xx, yy) y mantiene la estructura recursiva.
   -  Y → λ : Finaliza la derivación desde  Y .

### Paso 2: Verificación de las condiciones del lenguaje
El lenguaje  L = x^m y^n : n ≤ m ≤ 2n tiene dos condiciones principales:
1.  n ≤ m: Esto implica que siempre debe haber al menos tantos símbolos  x's como  y's.
2.  m ≤ 2n: Esto limita el número de símbolos  x's a como máximo el doble del número de símbolos  y's.

#### Análisis de las reglas:
- La producción  X → xXy  asegura que por cada símbolo agregado al inicio ( x) se agrega uno al final ( y), manteniendo la relación entre los extremos.
- La producción  Y → xxYy  permite agregar dos símbolos adicionales ( xx, yy), controlando que el número total de símbolos cumpla con la condición superior ( m ≤ 2n).
- Las producciones vacías ( X, Y → λ) permiten finalizar la derivación en cualquier momento, asegurando flexibilidad para cumplir con las restricciones.

### Paso 3: Ejemplo de derivación
Para generar una cadena válida como  x^4y^3:
1. Aplicar repetidamente la regla  X → xXy tres veces:
   - Derivación parcial:  
      S → X → xXy → xxXyy → xxxXyyy .
   - Resultado parcial: Tres pares ( xxx, yyy), cumpliendo con la condición mínima ( n = m = 3).
2. Pasar a trabajar con el no terminal  Y :
   - Aplicar la regla recursiva en  Y  para agregar un par adicional:
     - Derivación final:  
        xxxXyyy → xxxxYyyyyy .
3. Terminar aplicando las reglas vacías:
   - Resultado final:  
     Cadena generada:  xxxxxyyyyyy = x^4y^3.

### Paso 4: Conclusión
La gramática cumple con las condiciones definidas por el lenguaje dado ( n ≤ m ≤ 2n). Por lo tanto, la gramática es correcta.

### Respuesta Final
a) Correcta.
