# Problema: Equivalencia entre un autómata finito determinista (AFD) y una expresión regular.

## Enunciado:
Obténganse las expresiones regulares equivalentes a los siguientes autómatas finitos deterministas.

---

## Representación de los autómatas en formato de tabla:

### Autómata 1 (izquierda):
Este autómata procesa cadenas sobre el alfabeto  [, d, ] .

| Estado actual | Entrada | Nuevo estado |
|---------------|---------|--------------|
|  q_0      |  [  |  q_1     |
|  q_1      |  d  |  q_2     |
|  q_2      |  ]  |  q_3     |
|  q_3      |  d  |  q_3     |

- Estado inicial:  q_0 .  
- Estado final:  q_3 .

---

### Autómata 2 (derecha):
Este autómata procesa cadenas sobre el alfabeto  a, b, c .

| Estado actual | Entrada | Nuevo estado |
|---------------|---------|--------------|
|  p_0      |  a  |  p_1     |
|  p_0      |  b  |  p_2     |
|  p_1      |  a  |  p_1     |
|  p_1      |  b  |  p_2     |
|  p_2      |  c  |  p_f     |
|  p_f      | -       | -            |

- Estado inicial:  p_0 .  
- Estado final:  p_f .

---

## Obtención de las expresiones regulares equivalentes:

### Autómata 1:
El autómata reconoce cadenas que:
1. Comienzan con el símbolo "[".
2. Continúan con un único "d".
3. Siguen con el símbolo "]".
4. Opcionalmente, pueden tener cualquier cantidad de "d" adicionales después.

Expresión regular equivalente:

ER_1 = [d] d^*


---

### Autómata 2:
El autómata reconoce cadenas que:
1. Comienzan con una secuencia de "a" (incluyendo la cadena vacía).
2. Pueden alternar entre "a" y "b" cualquier número de veces.
3. Terminan con un único "c".

Expresión regular equivalente:

ER_2 = (a^*b)c


---

## Conclusión:
Las expresiones regulares equivalentes a los autómatas dados son:

1. Para el autómata 1:  
   d]d^*  

2. Para el autómata 2:  
   (a^*b)c
