# Problema: Regularidad de la estrella de Kleene de un lenguaje no regular

## Enunciado:
La estrella de Kleene de un lenguaje no regular L, ¿puede ser regular?

a) No, nunca  
b) Sí, para algún L.

## Solución:
La respuesta correcta es b) Sí, para algún L.

### Paso 1: Ejemplo de un lenguaje no regular
Consideremos el alfabeto {x} y definamos el lenguaje  

L = { x^p | p es un número primo }

Este lenguaje es conocido por ser no regular, ya que es imposible construir un autómata finito que controle la propiedad numérica (la primalidad) de la longitud de la cadena.

### Paso 2: Cálculo de la estrella de Kleene de L
La estrella de Kleene de L se define como:

L* = { w1 w2 … wk | k ≥ 0 y cada wi ∈ L }

Observamos que toda cadena de la forma x^n (para cualquier n ≥ 0) se puede obtener concatenando cadenas de L. En particular, si se tiene en L la cadena de longitud 1 (suponiendo en este contexto que 1 se considera primo o se incorpora de otra forma), entonces  

x^n = x · x · … · x (n veces)

y por tanto, toda cadena sobre el alfabeto {x} se encuentra en L*. Así,  

L* = { x }*

que es un lenguaje regular.

### Paso 3: Conclusión
Aunque L en sí es no regular, su estrella de Kleene L* resulta ser el conjunto de todas las cadenas sobre el alfabeto {x}, un lenguaje que es regular. Por ello, la respuesta es b) Sí, para algún L.
