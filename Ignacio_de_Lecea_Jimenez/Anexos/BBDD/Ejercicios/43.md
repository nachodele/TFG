# Problema: Que tipo de lenguaje genera la siguiente gramática

## Enunciado
Considere la siguiente gramática:

- S → xABy  
- A → xBC  
- A → yBz  
- B → yy  
- B → λ  
- C → xB  
- C → xyz  

El lenguaje generado por esta gramática es:  
a) Regular  
b) Independiente del contexto, no regular  

Solución: a) Regular

## Solución

### Paso 1: Análisis de la gramática
La gramática genera un lenguaje finito porque:
1. Las reglas de producción son limitadas y no permiten recursividad infinita.
2. Cada derivación termina después de un número finito de pasos.

#### Derivaciones posibles:
1. Desde  S :
   -  S → xABy .
2. Desde  A :
   -  A → xBC  o  A → yBz .
3. Desde  B :
   -  B → yy  o  B → λ .
4. Desde  C :
   -  C → xB  o  C → xyz .

Estas reglas generan exactamente 8 cadenas diferentes.

### Paso 2: Clasificación del lenguaje
1. Regularidad del lenguaje:
   - Un lenguaje finito siempre es regular porque puede representarse mediante una expresión regular que enumere todas las cadenas posibles.

2. Independencia de contexto:
   - Aunque la gramática es independiente de contexto, el lenguaje generado es regular debido a su naturaleza finita.

### Conclusión
El lenguaje generado por la gramática es regular, ya que contiene un número finito de cadenas y puede representarse mediante una expresión regular.

Respuesta correcta: a) Regular
