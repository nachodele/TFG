# Problema: Construcción de gramáticas regulares equivalentes a expresiones regulares

## Enunciado
Construya una gramática regular (GR) equivalente a las siguientes expresiones regulares:

1.  α = a · (a + b)^* + b^*   
2.  β = 10^*1(01^* + 1^*0)^*   
3.  δ = (a + b)^* · a + b^* 

## Solución

Gramática Regular Derecha (G3LD): reglas de la forma A → a o A → aB
Gramática Regular Izquierda: reglas de la forma A → a o A → Ba
Donde A y B son símbolos no terminales y a es un símbolo terminal.

### Gramática para α = a · (a + b)^* + b^*
Para construir una gramática regular derecha equivalente:
- Símbolos no terminales: S, A, B
- Símbolos terminales: a, b

- Reglas:
- S → aA | B (donde B genera b^*)
- A → aA | bA | λ (genera (a+b)^*)
- B → bB | λ (genera b^*)

### Gramática para β = 10^*1(01^* + 1^*0)^*
Para construir una gramática regular derecha equivalente:
- Símbolos no terminales: S, A, B, C, D
- Símbolos terminales: 0, 1

- Reglas:
- S → 1A
- A → 0A | 1B
- B → 0C | 1D | λ
- C → 1C | 0B | λ
- D → 1D | 0B | λ

### Gramática para δ = (a + b)^* · a + b^*
Para construir una gramática regular derecha equivalente:
- Símbolos no terminales: S, A, B
- Símbolos terminales: a, b

Reglas:
- S → aS | bS | a | B
- B → bB | λ

#### Observaciones adicionales
Para construir gramáticas regulares a partir de expresiones regulares, podemos utilizar el algoritmo basado en derivadas de expresiones regulares. Este método consiste en:

1. Calcular la derivada de la expresión regular respecto a cada símbolo terminal
2. Establecer un estado para cada expresión regular derivada única
3. Crear transiciones entre estados basadas en las derivadas
4. Convertir el autómata resultante en una gramática regular
5. Este método garantiza que obtengamos una gramática regular válida que represente exactamente el mismo lenguaje que la expresión regular original.
