# Problema: Simplificación de una gramática y conversión a Forma Normal de Chomsky (FNC)

## Enunciado  
Simplifique la siguiente gramática independiente de contexto (GIC) y encuentre otra gramática equivalente en Forma Normal de Chomsky (FNC) que genere  L(G) - λ :

Gramática original:  
-  S → aAa ∣ bBb ∣ λ   
-  A → C ∣ a   
-  B → C ∣ b   
-  C → CDE ∣ CD ∣ a   
-  D → A ∣ B ∣ ab   
-  E → dE 

## Solución

### Paso 1: Eliminación de símbolos no generativos  
Un símbolo es generativo si puede derivar una cadena de terminales.  

Símbolos no generativos identificados:  
-  E → dE  no genera terminales.  

Gramática simplificada:  
- Eliminar  E  y todas las reglas que la contienen:  
  -  C → CDE  se convierte en  C → CD .  

Producciones actualizadas:  
-  S → aAa ∣ bBb ∣ λ   
-  A → C ∣ a   
-  B → C ∣ b   
-  C → CD ∣ a   
-  D → A ∣ B ∣ ab   

### Paso 2: Eliminación de símbolos no accesibles  
Un símbolo es accesible si es alcanzable desde  S .  

Verificación:  
- Desde  S :  A, B  son accesibles.  
- Desde  A :  C  es accesible.  
- Desde  C :  D  es accesible.  
- Todos los símbolos restantes ( S, A, B, C, D ) son accesibles.  

### Paso 3: Eliminación de producciones vacías ( λ )  
Símbolos anulables:  
-  S → λ  es la única producción vacía.  

Gramática ajustada (eliminar  S → λ ):  
-  S → aAa ∣ bBb ∣ aA ∣ bB ∣ aa ∣ bb   

### Paso 4: Eliminación de reglas unitarias  
Las reglas unitarias son de la forma  X → Y .  

Proceso:  
1.  A → C :  
   - Sustituir  C → CD ∣ a :  
     -  A → CD ∣ a .  
2.  B → C :  
   - Sustituir  C → CD ∣ a :  
     -  B → CD ∣ a ∣ b .  
3.  D → A ∣ B :  
   - Sustituir  A → CD ∣ a  y  B → CD ∣ a ∣ b :  
     -  D → CD ∣ a ∣ b ∣ ab .  

Producciones actualizadas:  
-  S → aAa ∣ bBb ∣ aA ∣ bB ∣ aa ∣ bb   
-  A → CD ∣ a   
-  B → CD ∣ a ∣ b   
-  C → CD ∣ a   
-  D → CD ∣ a ∣ b ∣ ab   

### Paso 5: Conversión a Forma Normal de Chomsky (FNC)  

#### Reglas para terminales:  
-  X_a → a   
-  X_b → b   

#### Descomposición de producciones con más de dos símbolos:  
1.  S → aAa :  
   -  S → X_a Y_1 ,  Y_1 → A X_a .  
2.  S → bBb :  
   -  S → X_b Y_2 ,  Y_2 → B X_b .  
3.  D → ab :  
   -  D → X_a X_b .  

#### Producciones en FNC:  
-  S → X_a Y_1 ∣ X_b Y_2 ∣ X_a A ∣ X_b B ∣ X_a X_a ∣ X_b X_b   
-  Y_1 → A X_a   
-  Y_2 → B X_b   
-  A → CD ∣ X_a   
-  B → CD ∣ X_a ∣ X_b   
-  C → CD ∣ X_a   
-  D → CD ∣ X_a ∣ X_b ∣ X_a X_b   
-  X_a → a   
-  X_b → b   

### Conclusión  
La gramática simplificada en FNC genera  L(G) - λ . Todos los pasos garantizan que las producciones cumplan con las reglas de la FNC:  
1.  A → BC  (dos no terminales).  
2.  A → a  (un terminal).  
3. No hay producciones vacías ni unitarias.
