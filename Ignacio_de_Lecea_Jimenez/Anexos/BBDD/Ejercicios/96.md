# Problema: Palabras en un lenguaje

## Enunciado:
Sean A = {λ, ab} y B = {cd}. ¿Cuántas palabras tiene A^nB para un n arbitrario?

## Solución:
### Definiciones previas
1. Potencia de un lenguaje (A^n): Es el conjunto de todas las cadenas obtenidas concatenando exactamente n palabras del lenguaje A. Si |A| = k, entonces el número de palabras en A^n es:
   |A^n| = k^n

2. Concatenación de lenguajes (A^nB): Es el conjunto de todas las cadenas obtenidas concatenando cada palabra de A^n con cada palabra de B. Si |A^n| = k^n y |B| = m, entonces el número de palabras en A^nB es:
   |A^nB| = |A^n| · |B| = k^n · m

### Cálculo para los lenguajes dados
Dado que:
- A = {λ, ab}, entonces |A| = 2.
- B = {cd}, entonces |B| = 1.

1. Número de palabras en A^n:
   Según la fórmula, para cualquier n ≥ 0:
   |A^n| = 2^n

2. Número de palabras en A^nB:
   Al concatenar cada palabra de A^n con cada palabra de B, el número total es:
   |A^nB| = |A^n| · |B| = 2^n · 1 = 2^n

### Conclusión
El número de palabras en A^nB para un valor arbitrario de n ≥ 0 es:
|A^nB| = 2^n
