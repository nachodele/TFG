# Problema: Demostración

## Enunciado:
Sabemos que:

A* = A^0 ∪ A+ = {λ} ∪ A+

cabría esperar por tanto que:

A+ = A* \ {λ}

Probar que, en general, la expresión no es cierta. ¿Cuándo se cumple?

## Solución:
### Paso 1: Definición de A* y A+
- A* (cierre de Kleene): Es el conjunto de todas las concatenaciones posibles de cadenas del lenguaje A, incluyendo la cadena vacía λ. Formalmente:

  A* = ⋃_{i=0}^∞ A^i,

  donde A^0 = {λ} y A^i = A · A^{i-1} para i > 0.

- A+ (cierre positivo): Es el conjunto de todas las concatenaciones posibles de cadenas del lenguaje A, excluyendo la cadena vacía. Formalmente:

  A+ = ⋃_{i=1}^∞ A^i.

Por definición, se cumple que:

A* = {λ} ∪ A+.

### Paso 2: Propuesta de la igualdad
La expresión propuesta es:

A+ = A* \ {λ}.

Esto implica que si eliminamos la cadena vacía λ de A*, obtenemos exactamente A+.

### Paso 3: Contraejemplo para demostrar que no siempre es cierta
Consideremos un caso donde el lenguaje A = {λ}. En este caso:

- A* = ⋃_{i=0}^∞ A^i = {λ, λ, λ, ...} = {λ}.
- A+ = ⋃_{i=1}^∞ A^i = {λ, λ, ...} = {λ}.

Si aplicamos la operación propuesta:

A* \ {λ} = {λ} \ {λ} = ∅.

Claramente:

A+ ≠ A* \ {λ}.

Por lo tanto, la igualdad no se cumple en este caso.

### Paso 4: Condición para que se cumpla
Para que la igualdad sea válida, es necesario que el lenguaje A no contenga la cadena vacía (λ ∉ A). Si λ ∉ A, entonces:

- La única aparición de λ en A* proviene de A^0 = {λ}.
- Al eliminar λ de A*, obtenemos exactamente todas las concatenaciones no vacías definidas en A+.

En resumen, la igualdad se cumple si y solo si:

λ ∉ A.

### Conclusión:
La expresión propuesta A+ = A* \ {λ} no es válida en general. Sin embargo, se cumple cuando el lenguaje original A no contiene la cadena vacía (λ ∉ A).
