# Problema: Simulación de un AFD para las cadenas dadas.

## Enunciado:
Compruébese si las siguientes cadenas son reconocidas por los autómatas indicados, mostrando las transiciones que se producen paso a paso.

---

## Solución:
### AFD
#### Tabla de transiciones:
| Estado actual | Entrada | Nuevo estado |
|---------------|---------|--------------|
| 51            |  a  | 52           |
| 52            |  a  | 53           |
| 53            |  b  | 54           |
| 54            |  c  | 55           |
| 55            |  a  | 56           |
| 56            |  a  | 57           |
| 57            |  b  | 58           |
| 58            |  a  | 59           |
| 59            |  c  | 60           |
| 60            |  a  | 61           |
| 61            |  c  | 62           |

- Estado inicial:  51 .  
- Estado final:  62 .

#### Análisis de las cadenas:
1.  x = aabaca :
   - Transiciones:  
     - (51, 'a', 52), (52, 'a', 53), (53, 'b', 54), (54, 'a', REJECTED).  
   - Resultado: Rechazada.

2.  y = acababa :
   - Transiciones:  
     - (51, 'a', 52), (52, 'c', REJECTED).  
   - Resultado: Rechazada.

3.  z = baaabbacccc :
   - Transiciones:  
     - (51, 'b', REJECTED).  
   - Resultado: Rechazada.
