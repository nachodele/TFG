# Problema: Simulación de un AFN para las cadenas dadas.  

## Enunciado:  
Compruébese si reconocen o no las cadenas que se indican en cada caso, mostrando las transiciones que se van produciendo paso a paso.  

### Tabla de transiciones del AFN:  

| Estado | Entrada 'a'      | Entrada 'b'      | Entrada 'c'      |  
|--------|------------------|------------------|------------------|  
| q0     | {q0, q2}         | {q4}            | ∅                |  
| q1     | {q1}             | {q2, q4}        | {q0, q1, q3}     |  
| q2     | {q1, q3}         | ∅                | ∅                |  
| q3     | ∅                | ∅                | ∅                |  
| q4     | {q1}             | {q0, q1, q4}    | {q2, q3}         |  

Cadenas a analizar:  
- w = aacab  
- x = acabbcc  
- y = bbcac  
- z = accaa  

---

## Simulación paso a paso para cada cadena:  

#### 1. Cadena w = aacab:  
Transiciones realizadas:  
- (q_0, 'a') → q_0, q_2.  
- Desde q_0: (q_0, 'a') → q_0, q_2. Desde q_2: (q_2, 'a') → q_1, q_3.  
- Desde q_1: (q_1, 'c') → q_0, q_1, q_3. Desde q_3: no hay transición válida.  
- Desde q_0: (q_0, 'a') → q_0, q_2. Desde q_2: no hay transición válida.  
- Desde q_4: no hay transición válida con 'b'.  

Estado final alcanzado: No se alcanza un estado final.  
Resultado: No reconocida.  

#### 2. Cadena x = acabbcc:  
Transiciones realizadas:  
- (q_0, 'a') → q_0, q_2.  
- Desde q_0: (q_0, 'c') no tiene transición válida. Desde q_2: no hay transición válida con 'c'.  

Estado final alcanzado: No se alcanza un estado final.  
Resultado: No reconocida.  

#### 3. Cadena y = bbcac:  
Transiciones realizadas:  
- Desde q_0: no hay transición válida con 'b'.  

Estado final alcanzado: No se alcanza un estado final.  
Resultado: No reconocida.  

#### 4. Cadena z = accaa:  
Transiciones realizadas:
- (q_0, 'a') → q_0, q_2.  
- Desde q_0: no hay transición válida con 'c'. Desde q_2: no hay transición válida con 'c'.  

Estado final alcanzado: No se alcanza un estado final.  
Resultado: No reconocida.

Resultados para cada cadena:
