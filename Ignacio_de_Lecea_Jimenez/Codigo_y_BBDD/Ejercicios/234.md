# Problema: Longitud Máxima de Cadenas Aceptadas por un Autómata Finito.  

## Enunciado:  
Indicar si la siguiente afirmación es verdadera o falsa:  
*"Para todo autómata finito existe una longitud máxima tal que las cadenas que acepta el autómata nunca exceden dicha longitud."*  
a) Verdadera.  
b) Falsa.  

## Solución:  
La respuesta correcta es b) Falsa.  

### Justificación:  

1. Propiedad de los lenguajes regulares:  
   - Un autómata finito (determinista o no determinista) puede aceptar lenguajes regulares, los cuales pueden contener cadenas de longitud arbitrariamente grande.  
   - Por ejemplo, el lenguaje L = a^* (todas las cadenas formadas por cero o más repeticiones de a) es regular y contiene cadenas de cualquier longitud.  

2. Lema de bombeo:  
   - Según el lema de bombeo, para un lenguaje regular existe una longitud mínima n tal que cualquier cadena z con |z| ≥ n puede dividirse en tres partes
    z = uvw, donde v puede repetirse arbitrariamente (uv^kw ∈ L, para todo k ≥ 0).  
   - Esto implica que los lenguajes regulares pueden contener cadenas de longitud infinita, aunque sean generados por un autómata finito con un número limitado de estados.  

3. Contraejemplo:  
   - Considere el autómata que acepta el lenguaje L = a^*. Este autómata tiene un único estado que se transita repetidamente al leer cada a. No existe una longitud máxima para las cadenas aceptadas, ya que el lenguaje incluye cadenas de cualquier longitud.  

4. Conclusión:  
   - Aunque las cadenas aceptadas por un autómata finito son siempre de longitud finita, no existe una longitud máxima general para todas las cadenas aceptadas por el autómata.  

Respuesta correcta: b) Falsa.
