# Problema: La intersección de dos lenguajes independientes de contexto no regulares, ¿puede ser regular?

## Enunciado
La intersección de dos lenguajes independientes de contexto no regulares, ¿puede ser regular?

Opciones:  
a) Sí (en algún caso)  
b) No, nunca  

Solución: a) Sí (en algún caso)

## Solución

### Ejemplo
Considere los siguientes lenguajes:
1. L1 = {x^n y^n : n ≥ 0}, un lenguaje independiente de contexto no regular.
2. L2 = {x^n z^n : n ≥ 0}, otro lenguaje independiente de contexto no regular.

La intersección de estos dos lenguajes es:
L1 ∩ L2 = {λ},  
que es un lenguaje regular porque contiene únicamente la cadena vacía (λ).

### Conclusión
En algunos casos particulares, la intersección de dos lenguajes independientes de contexto no regulares puede ser un lenguaje regular.

Respuesta correcta: a) Sí (en algún caso)
