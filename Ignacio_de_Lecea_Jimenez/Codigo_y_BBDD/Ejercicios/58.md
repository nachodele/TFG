# Problema: Construcción de una gramática independiente de contexto (GIC) para un lenguaje

## Enunciado
Encuentra una gramática independiente de contexto (GIC) que genere el lenguaje  L = a^n b^n a^n : n ≥ 1 .

## Solución

### Paso 1: Análisis del lenguaje
El lenguaje  L  requiere que:
1. El número de  a  iniciales ( n ) coincida con el número de  b  centrales ( n ).
2. El número de  a  finales ( n ) también coincida con los anteriores.

Ejemplos válidos:  
-  n = 1 :  aba 
-  n = 2 :  aabbaa 
-  n = 3 :  aaabbbaaa 

### Paso 2: Demostración de que  L  no es independiente del contexto

El lenguaje  L = a^n b^n a^n  no es independiente del contexto. Esto se demuestra con el lema de bombeo para lenguajes no independientes del contexto:

1. Supongamos que  L  es independiente del contexto.
2. Sea  p  la constante de bombeo.
3. Tomemos la cadena  s = a^p b^p a^p .
4. Al dividir  s  en  uvwxy , se generan contradicciones:
    - Si  v  o  x  contienen múltiples símbolos (ej.  a  y  b ), al bombear se rompe el orden  a^n b^n a^n .
    - Si  v  y  x  están en regiones de  a -iniciales o  a -finales, bombear altera  n  de forma desigual.
5. Conclusión:  L  no cumple el lema de bombeo, por lo que no es independiente del contexto.

### Paso 3: Conclusión

No existe una gramática independiente del contexto (GIC) que genere  L .
- Las GIC solo pueden manejar dependencias anidadas (ej.  a^n b^n ) pero no relaciones triples ( a^n b^n a^n ).
- Para generar  L , se requiere una gramática sensible al contexto (Tipo 1), que puede verificar múltiples condiciones simultáneamente.

### Ejemplo de gramática sensible al contexto

S → aSBA | aBA  
BA → AB  
aA → aa  
B → b  

Esta gramática utiliza reglas sensibles al contexto para sincronizar las a-iniciales, b-centrales y a-finales.
