# Problema: Determinar si la cadena w = bcaab pertenece al lenguaje generado por la gramática G usando CYK

## Enunciado  
Dada la gramática en Forma Normal de Chomsky (FNC):  
- S → AB | AC | BC  
- A → BA | a  
- B → AC | b  
- C → DA  
- D → c  

Determinar mediante el algoritmo CYK si la cadena w = bcaab pertenece al lenguaje.


## Solución

### Paso 1: Aplicación del algoritmo CYK  
Cadena: `b c a a b` (longitud 5).  

#### Inicialización (subcadenas de longitud 1):  
| Posición | Carácter | No terminales generadores |  
|----------|----------|---------------------------|  
| 1        | b        | B (B → b)             |  
| 2        | c        | D (D → c)             |  
| 3        | a        | A (A → a)             |  
| 4        | a        | A (A → a)             |  
| 5        | b        | B (B → b)             |  

---

#### Subcadenas de longitud 2:  
1. Posiciones 1-2 ("bc"):  
   - Combinaciones: B (1) + D (2) → Buscar reglas que generen BD.  
   - Ninguna regla produce BD.  
   - Resultado: ∅.  

2. Posiciones 2-3 ("ca"):  
   - Combinaciones: D (2) + A (3) → Buscar reglas para DA.  
   - C → DA → Añadir C.  
   - Resultado: C.  

3. Posiciones 3-4 ("aa"):  
   - Combinaciones: A (3) + A (4) → Buscar reglas para AA.  
   - Ninguna regla.  
   - Resultado: ∅.  

4. Posiciones 4-5 ("ab"):  
   - Combinaciones: A (4) + B (5) → Buscar reglas para AB.  
   - S → AB y C → AB → Añadir S, C.  
   - Resultado: S, C.  

---

#### Subcadenas de longitud 3:  
1. Posiciones 1-3 ("bca"):  
   - Divisiones:  
     - (1) B + (2-3) C → Buscar reglas para BC.  
       - S → BC → Añadir S.  
     - (1-2) ∅ + (3) A → Sin resultados.  
   - Resultado: S.  

2. Posiciones 2-4 ("caa"):  
   - Divisiones:  
     - (2) D + (3-4) ∅ → Sin resultados.  
     - (2-3) C + (4) A → Buscar reglas para CA.  
       - Ninguna regla.  
   - Resultado: ∅.  

3. Posiciones 3-5 ("aab"):  
   - Divisiones:  
     - (3) A + (4-5) S/C → Buscar reglas para AS o AC.  
       - Ninguna regla.  
     - (3-4) ∅ + (5) B → Sin resultados.  
   - Resultado: ∅.  

---

#### Subcadenas de longitud 4:  
1. Posiciones 1-4 ("bcaa"):  
   - Divisiones:  
     - (1-3) S + (4) A → Buscar reglas para SA.  
       - Ninguna regla.  
     - (1-2) ∅ + (3-4) ∅ → Sin resultados.  
   - Resultado: ∅.  

2. Posiciones 2-5 ("caab"):  
   - Divisiones:  
     - (2-3) C + (4-5) S/C → Buscar reglas para CS o CC.  
       - Ninguna regla.  
     - (2-4) ∅ + (5) B → Sin resultados.  
   - Resultado: ∅.  

---

#### Subcadena de longitud 5 ("bcaab"):  
- Divisiones:  
  - (1-3) S + (4-5) S/C → Buscar reglas para SS o SC.  
    - Ninguna regla.  
  - (1-4) ∅ + (5) B → Sin resultados.  
- Resultado: ∅.  

---

### Paso 2: Tabla CYK final (simplificada)  
| Longitud | Posiciones | No terminales |  
|----------|------------|---------------|  
| 1        | 1-5        | B, D, A, A, B |  
| 2        | 1-2, ..., 4-5 | ∅, C, ∅, S/C |  
| 3        | 1-3, ..., 3-5 | S, ∅, ∅ |  
| 4        | 1-4, 2-5   | ∅, ∅ |  
| 5        | 1-5        | ∅ |  

---

### Conclusión  
El símbolo inicial S no aparece en la celda correspondiente a la cadena completa (1-5).  

Respuesta: La cadena `bcaab` no pertenece al lenguaje generado por la gramática corregida.
