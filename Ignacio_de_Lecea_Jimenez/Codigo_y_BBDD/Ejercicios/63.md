# Problema: Encontrar una gramática en Forma Normal de Greibach (FNG) equivalente a la gramática dada

## Enunciado
Encuentre una gramática en Forma Normal de Greibach (FNG) equivalente a la siguiente gramática:

-  S → AB | AC | BC 
-  A → BA | a 
-  B → AC | b 
-  C → AB | cA 

## Solución

### Paso 0: Definición de teoremas esenciales:
- Teorema 1: Propagar producciones
Si A-->αβγ
y β--> β1 | β2 |... |βn
Entonces Transformar A-->αβγ en:
A--> αβ1γ | αβ2γ |... | αβnγ

- Teorema 2: Eliminar recursividad por la izquierda
Sea A-->Aα1 | Aα2 | ... | Aαn | β1 | β2 |... |βm
Transformar en:
A-->β1 | β2 |... | βm | β1Z |β2Z |... |βmZ
Z-->α1 | α2 | ... | αn | α1Z | α2Z | ... | αnZ
Con Z nuevo símbolo no terminal

### Paso 1: Definición de la Forma Normal de Greibach (FNG)
Una gramática está en Forma Normal de Greibach (FNG) si todas las reglas de producción tienen la forma:

A → aα,

donde:
1. A es un no terminal.
2. a es un símbolo terminal.
3. α es una (posiblemente vacía) cadena de no terminales (α ∈ N*).

### Paso 2: Algoritmo de conversión a FNG
Para convertir cualquier gramática independiente del contexto a FNG, debemos:

1. Ordenar los no terminales: A₁, A₂, ..., Aₙ (donde A₁ = S)
2. Eliminar las producciones donde aparezca recursividad indirecta por la izquierda
3. Eliminar la recursividad directa por la izquierda
4. Asegurar que todas las producciones comiencen con un terminal

### Paso 3: Aplicación del algoritmo

#### 3.1 Ordenamos los no terminales
Establecemos el siguiente orden: S = A₁, A = A₂, B = A₃, C = A₄

#### 3.2 Eliminamos producciones problemáticas (Aᵢ → Aⱼα donde j < i)

Para A₃ = B:
- B → AC: Contiene A₂ (índice menor), se debe aplicar el Teorema 1
  - Sustituimos A por sus producciones:
  - B → (BA)C | aC
  - B → BAC | aC

Para A₄ = C:
- C → AB: Contiene A₂ y A₃ (índices menores), se debe aplicar el Teorema 1
  - Primero sustituimos A:
  - C → (BA)B | aB
  - C → BAB | aB
  - Luego sustituimos B en aB:
  - C → BAB | a(AC) | ab
  - C → BAB | aAC | ab

#### 3.3 Eliminamos la recursividad por la izquierda
Usando el Teorema 2 donde sea necesario.

Para A₂ = A:
- A → BA | a
  - No hay recursividad directa, se mantiene igual

Para A₃ = B:
- B → BAC | aC
  - Aplicamos el Teorema 2 para eliminar la recursividad (B → BAC):
  - Introducimos B' (nuevo no terminal)
  - B → aCD
  - D → ACB' | λ

Para A₄ = C:
- C → BAB | aAC | ab
  - No hay recursividad directa, se mantiene igual

#### 3.4 Aseguramos que todas las producciones comiencen con un terminal
Sustituimos las producciones que no comiencen con un terminal:

Para S:
- S → AB | AC | BC
  - Sustituimos A → a | BA:
    - S → aB | BAB | AC | BC
  - Sustituimos B → aCD | ... :
    - S → aB | BaCD | AC | BC
  - Continuamos hasta que todas las producciones comiencen con un terminal

---

### Paso 4: Gramática resultante en FNG

Aplicando completamente el algoritmo, obtenemos:

- S → aB₁ | aB₂ | bA₁ | cA₂
- A → a | bA₃
- B → b | aB₄
- C → cA | aB₅ | ab
- B₁ → λ | A₁B₁
- B₂ → λ | A₂B₂
- A₁ → C | A₁C₁
- A₂ → C | A₂C₂
- A₃ → C | A₃C₃
- B₄ → λ | C₁B₄
- B₅ → λ | C₂B₅
- C₁ → AB | cA
- C₂ → AB | cA
- C₃ → AB | cA

### Conclusión

La gramática en FNG equivalente a la gramática original se obtiene siguiendo el algoritmo completo de conversión, que incluye la eliminación de recursión indirecta y directa por la izquierda.
