# Problema: Determinar si una cadena pertenece al lenguaje generado por la gramática G utilizando el algoritmo CYK

## Enunciado
Dada la gramática G:
1. S → AB | AC | BC 
2. A → BC | a 
3. B → AC | b 
4. C → AB | CA | B 

Determinar, utilizando el algoritmo CYK, si la cadena w = aababb pertenece al lenguaje generado por G.

## Solución

### Paso 1: Convertir la gramática a Forma Normal de Chomsky (FNC)
Para aplicar el algoritmo CYK, la gramática debe estar en FNC, donde todas las reglas tienen la forma A → BC o A → a.

Problema identificado: La regla C → B es una producción unitaria que viola los requisitos de FNC.

#### Eliminar la producción unitaria usando Algoritmo 4:
1. Identificar la producción unitaria: C → B
2. Sustituir esta producción con todas las producciones no unitarias de B:
   - B → AC, por lo tanto: C → AC
   - B → b, por lo tanto: C → b

Gramática en FNC:
1. S → AB | AC | BC 
2. A → BC | a 
3. B → AC | b 
4. C → AB | CA | AC | b

### Paso 2: Aplicación del algoritmo CYK
Cadena a analizar: w = aababb (longitud n = 6)

#### Inicialización (subcadenas de longitud 1):
| Posición | Carácter | No terminales |
|----------|----------|---------------|
| 1        | a        | A             |
| 2        | a        | A             |
| 3        | b        | B, C          |
| 4        | a        | A             |
| 5        | b        | B, C          |
| 6        | b        | B, C          |

Nota: Ahora C también genera b directamente, tras eliminar la producción unitaria.

#### Subcadenas de longitud 2:
1. [1,2] ("aa"):
   - A+A: Ninguna regla produce AA
   - Resultado: ∅

2. [2,3] ("ab"):
   - A+B: S → AB
   - A+C: S → AC
   - Resultado: S

3. [3,4] ("ba"):
   - B+A: Ninguna regla
   - C+A: C → CA
   - Resultado: C

4. [4,5] ("ab"):
   - A+B: S → AB
   - A+C: S → AC
   - Resultado: S

5. [5,6] ("bb"):
   - B+B: Ninguna regla
   - B+C: Ninguna regla
   - C+B: Ninguna regla
   - C+C: Ninguna regla
   - Resultado: ∅

#### Subcadenas de longitud 3:
1. [1,3] ("aab"):
   - A(1)+∅(2): Ninguna regla
   - ∅(1-2)+B/C(3): Ninguna regla
   - Resultado: ∅

2. [2,4] ("aba"):
   - S(2-3)+A(4): Ninguna regla
   - A(2)+C(3-4): Ninguna regla
   - Resultado: ∅

3. [3,5] ("bab"):
   - B/C(3)+S(4-5): Ninguna regla
   - C(3-4)+B/C(5): S → CB
   - Resultado: S

4. [4,6] ("abb"):
   - S(4-5)+B/C(6): Ninguna regla
   - A(4)+∅(5-6): Ninguna regla
   - Resultado: ∅

#### Subcadenas de longitud 4:
1. [1,4] ("aaba"): Resultado: ∅
2. [2,5] ("abab"): Resultado: ∅
3. [3,6] ("babb"): Resultado: ∅

#### Subcadenas de longitud 5:
1. [1,5] ("aabab"): Resultado: ∅

#### Subcadena de longitud 6:
1. [1,6] ("aababb"): Resultado: ∅

### Conclusión
El símbolo inicial S no aparece en la celda correspondiente a la cadena completa [1,6].

Respuesta: La cadena w = aababb no pertenece al lenguaje generado por la gramática G.
