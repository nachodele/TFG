# Problema: Construcción de una gramática regular (GR) equivalente a una expresión regular

## Enunciado
Construya formalmente una gramática regular que genere un lenguaje equivalente al lenguaje caracterizado por la siguiente expresión regular:

α = ab^* (a + ab^*)

## Solución

### Paso 1: Método de las derivadas para transformar ER en GR
Para convertir una expresión regular a una gramática regular de forma sistemática, debemos utilizar el método de las derivadas, que consta de:

1. Calcular las derivadas sucesivas de la expresión regular.
2. Construir la gramática a partir de esas derivadas.
3. Verificar la corrección de la gramática resultante.

### Paso 2: Cálculo de las derivadas
Expresión original: α₀ = ab^* (a + ab^*)

Derivadas respecto a los símbolos del alfabeto:

- Da(α₀) = Da(ab^* (a + ab^*))
  = Da(a)·b^* (a + ab^*) + δ(a)·Da(b^* (a + ab^*))
  = λ·b^* (a + ab^*) + ∅
  = b^* (a + ab^*) = α₁

- Db(α₀) = Db(ab^* (a + ab^*))
  = Db(a)·b^* (a + ab^*) + δ(a)·Db(b^* (a + ab^*))
  = ∅ + ∅ = ∅

- Da(α₁) = Da(b^* (a + ab^*))
  = Da(b^*)·(a + ab^*) + δ(b^*)·Da(a + ab^*)
  = ∅ + λ·(λ + b^*)
  = λ + b^* = α₂

- Db(α₁) = Db(b^* (a + ab^*))
  = Db(b^*)·(a + ab^*) + δ(b^*)·Db(a + ab^*)
  = b^*·(a + ab^*) + λ·∅
  = b^* (a + ab^*) = α₁

- Da(α₂) = Da(λ + b^*) = Da(λ) + Da(b^*) = ∅ + ∅ = ∅

- Db(α₂) = Db(λ + b^*) = Db(λ) + Db(b^*) = ∅ + b^* = b^* = α₃

- Da(α₃) = Da(b^*) = ∅

- Db(α₃) = Db(b^*) = b^* = α₃

### Paso 3: Análisis de nulabilidad
Verificamos qué expresiones pueden derivar la cadena vacía (λ):

- α₀ = ab^* (a + ab^*): No deriva λ
- α₁ = b^* (a + ab^*): No deriva λ
- α₂ = λ + b^*: Deriva λ (contiene λ explícitamente)
- α₃ = b^*: Deriva λ (por definición de la estrella de Kleene)

### Paso 4: Construcción de la gramática regular
Aplicando el algoritmo de construcción de gramáticas a partir de derivadas:

1. Si Da(α) = β, β≠∅, crear regla: α → aβ
2. Si λ ∈ L(Da(α)), crear regla: α → a
3. Si λ ∈ L(α), crear regla: α → λ
4. Si Da(α) = ∅, no generar regla

Asignación de no terminales:
- α₀ = S (símbolo inicial)
- α₁ = A
- α₂ = B
- α₃ = C

Producciones resultantes:
- Da(α₀) = α₁, por lo tanto: S → aA
- Db(α₀) = ∅, no se genera regla
- Da(α₁) = α₂, por lo tanto: A → aB
- Db(α₁) = α₁, por lo tanto: A → bA
- λ ∈ L(Da(α₁)), por lo tanto: A → a
- Da(α₂) = ∅, no se genera regla
- Db(α₂) = α₃, por lo tanto: B → bC
- λ ∈ L(α₂), por lo tanto: B → λ
- Da(α₃) = ∅, no se genera regla
- Db(α₃) = α₃, por lo tanto: C → bC
- λ ∈ L(α₃), por lo tanto: C → λ

### Paso 5: Gramática regular final

G = ({a, b}, {S, A, B, C}, S, P)

Donde P contiene las siguientes producciones:
- S → aA
- A → aB | bA | a
- B → bC | λ
- C → bC | λ

### Paso 6: Verificación de la gramática
Comprobemos que la gramática genera correctamente algunas cadenas del lenguaje:

- "aa":
  S → aA → aa

- "aba":
  S → aA → abA → aba 

- "aab":
  S → aA → aB → abC → aab 

- "abba":
  S → aA → abA → abbA → abba 

La gramática construida mediante el método de las derivadas genera correctamente el lenguaje definido por la expresión regular ab^* (a + ab^*).
