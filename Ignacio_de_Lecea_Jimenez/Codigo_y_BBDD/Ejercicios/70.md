# Problema: Construcción de una gramática en Forma Normal de Greibach (FNG) para un lenguaje  L 

## Enunciado  
Diseñar una gramática en Forma Normal de Greibach (FNG) que genere el lenguaje:  
 L =  a^n b^m ∣ m ≥ n, \, n ≥ 1.  

## Solución

### Paso 1: Análisis del lenguaje  
El lenguaje  L  requiere:  
1. Al menos un "a" ( n ≥ 1 ).  
2. Al menos tantos "b" como "a" ( m ≥ n ).  

Ejemplos válidos:  
-  ab ,  aabb ,  aaabbb ,  abbb .  

Ejemplos inválidos:  
-  aab  ( m=1 < n=2 ),  a  ( m=0 < n=1 ).  

### Paso 2: Construcción de la gramática en FNG  
Una gramática en Forma Normal de Greibach (FNG) requiere que todas las reglas sean de la forma:  
 A → aα ,  
donde  a  es un terminal y  α  es una cadena (posiblemente vacía) de no terminales.  

#### Gramática propuesta:  
1. Símbolo inicial:  
   -  S   

2. Reglas:  
   -  S → aSB ∣ aB   
   -  B → b ∣ bB   

### Paso 3: Explicación de las reglas  
1. Regla  S → aSB :  
   - Genera un "a" y obliga a generar al menos un "b" por cada "a" mediante  B .  
   - Permite añadir más "a" y "b" simultáneamente ( SB ).  

2. Regla  S → aB :  
   - Base para generar el primer "a" y al menos un "b".  

3. Regla  B → b ∣ bB :  
   - Genera "b" adicionales, garantizando  m ≥ n .  

### Paso 4: Validación con ejemplos  

#### Ejemplo 1:  ab  ( n=1, m=1 )  
-  S → aB → ab .  

#### Ejemplo 2:  aabb  ( n=2, m=2 )  
-  S → aSB → aaSBB → aabB → aabb .  

#### Ejemplo 3:  aaabbb  ( n=3, m=3 )  
-  S → aSB → aaSBB → aaaSBBB → aaabBB → aaabbB → aaabbb .  

#### Ejemplo 4:  abbb  ( n=1, m=3 )  
-  S → aB → abB → abbB → abbb .  

### Conclusión  
La gramática en FNG que genera  L  es:  
-  S → aSB ∣ aB   
-  B → b ∣ bB   

Cumple con:  
1. Todas las reglas están en FNG.  
2. Garantiza  m ≥ n ≥ 1 .  
3. No genera cadenas inválidas como  aab  o  a .
