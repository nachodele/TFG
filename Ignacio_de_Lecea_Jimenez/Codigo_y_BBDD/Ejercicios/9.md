# Problema: Verificar si la gramática genera el lenguaje dado

## Enunciado
Sea L el lenguaje x^m y^n tal que n ≤ m ≤ 2n. Determine si la siguiente gramática es correcta para generar L:

### Gramática propuesta:
- S → X  
- S → Y  
- X → xXy  
- Y → xxYy  
- X → λ  
- Y → λ  

Opciones:  
a) Correcta.  
b) Incorrecta.  

Solución propuesta: b) Incorrecta. No puede generar x³y². Autómata no determinista

## Solución

### Paso 1: Condiciones del lenguaje L = x^m y^n
El lenguaje L está definido por las restricciones:  
1. n ≤ m: El número de símbolos x debe ser al menos igual al número de símbolos y.  
2. m ≤ 2n: El número de símbolos x no puede exceder el doble del número de símbolos y.  

Ejemplos de cadenas válidas:  
- xy, xxy, xyy, xxxy, xxxyy.  

Cadenas no válidas:  
- yx, xxxyyy (no cumplen las condiciones).  

### Paso 2: Análisis de la gramática propuesta
La gramática tiene dos producciones principales desde el símbolo inicial:  

1. Producción desde S → X:  
   - Genera cadenas con igual cantidad de x e y:  
     - xy, xxyy, xxxyyy.  
   - Solo cubre casos donde m = n.  

2. Producción desde S → Y:  
   - Genera cadenas donde x es exactamente el doble de y:  
     - xxy, xxxxyy.  
   - Solo cubre casos donde m = 2n.  

Limitación:  
No genera cadenas donde n < m < 2n (ejemplo: x³y²).  

### Paso 3: Contraejemplo
La cadena x³y² (m=3, n=2) cumple:  
- n = 2 ≤ m = 3 ≤ 2n = 4.  

Derivación imposible:  
- Desde X: Solo genera x²y² o x³y³.  
- Desde Y: Solo genera x⁴y².  

### Conclusión
La gramática no cubre todas las combinaciones válidas de m y n.  

Respuesta correcta:  
b) Incorrecta.
