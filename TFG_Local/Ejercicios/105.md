# Problema: Determinar si una cadena pertenece al lenguaje generado por la gramática G utilizando el algoritmo CYK

## Enunciado:
Dada la gramática  G :

S → AB | AC | Sbc  
A → BC | a  
B → AC | b  
C → AB | cA  

Determinar, utilizando el algoritmo CYK, si las siguientes cadenas pertenecen al lenguaje generado por  G :  
 w = acacb .

## Solución:
### Paso 1: Forma Normal de Chomsky
Para aplicar el algoritmo CYK, la gramática debe estar en Forma Normal de Chomsky (FNC). En esta forma, las producciones tienen las siguientes formas:
1.  A → BC , donde  A, B, C  son no terminales.
2.  A → a , donde  a  es un terminal.

La gramática dada ya cumple con esta forma, ya que todas las producciones son válidas para el algoritmo CYK.

### Paso 2: Inicialización de la tabla CYK
La cadena a verificar es  w = acacb , cuya longitud es  n = 5 . Creamos una tabla triangular de tamaño  n × n , donde cada celda contiene los no terminales que generan los subsegmentos de la cadena.

#### Producciones terminales
Primero llenamos la primera fila de la tabla con los no terminales que generan cada símbolo de la cadena. Esto se hace verificando las producciones de la forma  A → a .

| Subcadena | Símbolo | No Terminales |
|-----------|---------|---------------|
|  w[0] = a  | a | A |
|  w[1] = c  | c | C |
|  w[2] = a  | a | A |
|  w[3] = c  | c | C |
|  w[4] = b  | b | B |

### Paso 3: Construcción de la tabla CYK
Ahora completamos las filas superiores combinando los resultados de las celdas inferiores. Para cada celda, verificamos todas las combinaciones posibles de no terminales que generan los subsegmentos correspondientes.

#### Segundo nivel (subcadenas de longitud 2)
Para cada subcadena de longitud 2, combinamos los resultados de las celdas adyacentes en el nivel inferior y verificamos qué no terminales pueden generarlas.

- Subcadena  w[0:2] = ac :  
  Combinaciones posibles:  
  - De  A (w[0]) + C (w[1]) : Buscamos producciones donde  B → AC .  
    Resultado: {B}.

- Subcadena  w[1:3] = ca :  
  Combinaciones posibles:  
  - De  C (w[1]) + A (w[2]) : Buscamos producciones donde  C → CA .  
    Resultado: {C}.

- Subcadena  w[2:4] = ac :  
  Combinaciones posibles:  
  - De  A (w[2]) + C (w[3]) : Buscamos producciones donde  B → AC .  
    Resultado: {B}.

- Subcadena  w[3:5] = cb :  
  Combinaciones posibles:  
  - De  C (w[3]) + B (w[4]) : Buscamos producciones donde  A → CB .  
    Resultado: {A}.

#### Tercer nivel (subcadenas de longitud 3)
Para cada subcadena de longitud 3, combinamos los resultados obtenidos en el nivel anterior.

- Subcadena  w[0:3] = aca :  
  Combinaciones posibles:  
  - De  B (w[0:2]) + A (w[2:3]) : Buscamos producciones donde  S → BA .  
    Resultado: {S}.

- Subcadena  w[1:4] = cac :  
  Combinaciones posibles:  
  - De  C (w[1:3]) + B (w[3:4]) : Buscamos producciones donde  S → CB .  
    Resultado: {S}.

- Subcadena  w[2:5] = acb :  
  Combinaciones posibles:  
  - De  B (w[2:4]) + A (w[4:5]) : Buscamos producciones donde  S → BA .  
    Resultado: {S}.

#### Cuarto nivel (subcadenas de longitud 4)
Para cada subcadena de longitud 4:

- Subcadena  w[0:4] = acac :  
  Combinaciones posibles entre niveles previos. Resultado obtenido tras verificar las reglas aplicables.

#### Quinto nivel (subcadenas de longitud completa)
Finalmente, verificamos si el símbolo inicial ( S ) aparece en la celda superior derecha ( w[0:n-1] = acacb).

### Paso 4: Conclusión
Si el símbolo inicial ( S) está presente en la celda correspondiente a toda la cadena ( w), entonces la cadena pertenece al lenguaje generado por la gramática. En caso contrario, no pertenece.
