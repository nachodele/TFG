# Problema: Lenguaje generado por una gramática

## Enunciado:
Tenemos un alfabeto {x, y} tal que x vale 5 ptas. e y vale 10 ptas. Sea L el lenguaje de las cadenas que valen 20 ptas. ¿Es correcta la siguiente gramática para generar L?

1. S → xX  
2. S → yY  
3. X → xY  
4. X → yZ  
5. Y → xZ  
6. Y → y  
7. Z → x  

## Solución:
### Paso 1: Interpretación del problema
El lenguaje L está formado por todas las cadenas sobre el alfabeto {x, y} cuya suma de valores sea exactamente 20 ptas. Dado que:
- Cada x vale 5 ptas.
- Cada y vale 10 ptas.

Las cadenas válidas deben cumplir que la suma de los valores de los símbolos sea igual a 20. Esto implica que las combinaciones posibles son:
- Cuatro x: xxxx = 5 + 5 + 5 + 5 = 20.
- Dos x y un y: xxy = 5 + 5 + 10 = 20.
- Un x y un yx: xyx = 5 + 10 + 5 = 20.
- Dos y: yy = 10 + 10 = 20.

### Paso 2: Análisis de la gramática propuesta
La gramática propuesta tiene las siguientes reglas:

1. **S → xX:** El símbolo inicial genera una cadena que comienza con un "x" seguido por una derivación desde el no terminal X.  
2. **S → yY:** El símbolo inicial genera una cadena que comienza con un "y" seguido por una derivación desde el no terminal Y.  
3. **X → xY:** El no terminal X genera una cadena que contiene un "x" seguido por una derivación desde el no terminal Y.  
4. **X → yZ:** El no terminal X genera una cadena que contiene un "y" seguido por una derivación desde el no terminal Z.  
5. **Y → xZ:** El no terminal Y genera una cadena que contiene un "x" seguido por una derivación desde el no terminal Z.  
6. **Y → y:** El no terminal Y genera directamente el terminal "y".  
7. **Z → x:** El no terminal Z genera directamente el terminal "x".

### Paso 3: Verificación de las cadenas generadas
Analicemos si la gramática puede generar todas las cadenas válidas en el lenguaje:

1. Para la cadena "xxxx" (xxxx = 20):  
   - Aplicamos:  
     - S → xX → xxY → xxxZ → xxxx.

2. Para la cadena "xxy" (xxy = 20):  
   - Aplicamos:  
     - S → xX → xxY → xxy.

3. Para la cadena "xyx" (xyx = 20):  
   - Aplicamos:  
     - S → xX → xyZ → xyx.

4. Para la cadena "yy" (yy = 20):  
   - Aplicamos:  
     - S → yY → yy.

La gramática propuesta puede generar todas las cadenas válidas en el lenguaje.

### Conclusión:
La gramática es **correcta** para generar el lenguaje definido por todas las cadenas sobre el alfabeto {x, y} cuya suma de valores sea exactamente 20 ptas.
