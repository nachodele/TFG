# Problema: Construcción de un autómata determinista (AD).

## Enunciado:
¿Es cierto que el siguiente diagrama representa un autómata determinista de cuatro estados?

---

## Solución:
### Representación del autómata en formato de tabla:
El autómata finito determinista (AFD) tiene los siguientes estados y transiciones:

| Estado actual | Entrada | Nuevo estado |
|---------------|---------|--------------|
|  q_0      |  x  |  q_1     |
|  q_0      |  y  |  q_2     |
|  q_0      |  z  |  q_3     |
|  q_1      |  x  |  q_1     |
|  q_1      |  y  |  q_2     |
|  q_1      |  z  |  q_3     |
|  q_2      |  x  |  q_1     |
|  q_2      |  y  |  q_2     |
|  q_2      |  z  |  q_3     |
|  q_3      |  x  |  q_1     |
|  q_3      |  y  |  q_2     |
|  q_3      |  z  |  q_3     |

- **Estado inicial:**  q_0 .  
- **Estado final:** Según el diagrama, al menos uno de los estados es final (representado por un doble círculo).

### Análisis del autómata:
El diagrama muestra un autómata con los siguientes elementos:

1. **Estados:**
   - Hay cuatro estados representados por círculos:
     - Un estado inicial (marcado con una flecha entrante sin origen).
     - Un estado final (representado por un doble círculo).
     - Dos estados intermedios.

2. **Transiciones:**
   - Cada transición está etiquetada con un símbolo del alfabeto  x, y, z .
   - Para cada estado y cada símbolo de entrada, existe exactamente una transición definida hacia otro estado o hacia sí mismo.

3. **Determinismo:**
   - Un autómata finito determinista (AFD) debe cumplir con las siguientes propiedades:
     - Para cada estado y cada símbolo del alfabeto, existe como máximo una transición definida.
   - Analizando el diagrama, se observa que:
     - Desde cada estado, hay exactamente una transición para cada símbolo ( x ,  y ,  z ).
     - No hay ambigüedad en las transiciones.

4. **Cantidad de estados:**
   - El diagrama tiene exactamente cuatro estados distintos.
---

### Conclusión:
El autómata finito determinista tiene cuatro estados ( q_0, q_1, q_2, q_3 ) y cumple con las propiedades de un AFD. Por lo tanto, la respuesta es **sí**, el diagrama representa un autómata determinista de cuatro estados.
