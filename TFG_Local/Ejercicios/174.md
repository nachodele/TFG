# Problema: Longitud máxima de las cadenas aceptadas por un autómata finito

## Enunciado:
Indicar si la siguiente afirmación es verdadera o falsa:  
“Para todo autómata finito existe una longitud máxima tal que las cadenas que acepta el autómata nunca exceden dicha longitud.”

a) Verdadera  
b) Falsa

## Solución:
La respuesta correcta es **b) Falsa**.

### Explicación:
- Por definición, cada cadena aceptada por un autómata finito tiene una longitud finita.
- Sin embargo, muchos autómatas finitos aceptan lenguajes infinitos, donde no existe un límite superior (una longitud máxima) para las cadenas aceptadas.  
  Es decir, aunque cualquier cadena individual es de longitud finita, no hay una cota máxima para la longitud de las cadenas en el lenguaje.
