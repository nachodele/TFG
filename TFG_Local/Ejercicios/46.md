# Problema: ¿Existe una gramática  G  tal que  L(G) = L_1 ∩ L_2  para dos lenguajes independientes de contexto  L_1  y  L_2 ?

## Enunciado
Dados dos lenguajes independientes de contexto  L_1  y  L_2 , ¿existe una gramática  G  tal que  L(G) = L_1 ∩ L_2 ?

Opciones:  
a) Sí, siempre  
b) No necesariamente  

Solución: **b) No necesariamente**

## Solución

### Paso 1: Propiedades de los lenguajes independientes de contexto
Los lenguajes independientes de contexto no son cerrados bajo la operación de intersección. Esto significa que, aunque  L_1  y  L_2  sean independientes de contexto, su intersección  L_1 ∩ L_2  no necesariamente pertenece al conjunto de lenguajes independientes de contexto.

### Paso 2: Contraejemplo
Considere los siguientes lenguajes:
-  L_1 = a^n b^n c^m : n, m ≥ 0 , que es independiente de contexto.
-  L_2 = a^n b^m c^m : n, m ≥ 0 , que también es independiente de contexto.

La intersección de estos dos lenguajes es:

L_1 ∩ L_2 = a^n b^n c^n : n ≥ 0.


El lenguaje resultante  L_1 ∩ L_2 = a^n b^n c^n : n ≥ 0  no es independiente de contexto porque requiere comparar tres cantidades iguales ( n = n = n ), lo cual excede las capacidades de las gramáticas libres del contexto.

### Paso 3: Conclusión
No siempre existe una gramática libre del contexto que genere la intersección de dos lenguajes independientes de contexto. Esto se debe a que los lenguajes independientes de contexto no son cerrados bajo la operación de intersección.

**Respuesta correcta:** **b) No necesariamente**
