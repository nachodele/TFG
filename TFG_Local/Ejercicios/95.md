# Problema: Elementos en un lenguaje

## Enunciado:
Se supone que  L = λ . Obtener  L^n  para un  n  arbitrario.

## Solución:
### **Definición previa**
1. **Potencia de un lenguaje ( L^n )**: Es el conjunto de todas las cadenas obtenidas concatenando exactamente  n  palabras del lenguaje  L . Formalmente:
   -  L^0 = λ , donde  λ  es la palabra vacía.
   -  L^n = L^{n-1} · L, n > 0 , donde "·" denota la concatenación.

### **Cálculo de  L^n **
Dado que  L = λ , tenemos lo siguiente:

1. ** n = 0 :**
   - Por definición,  L^0 = λ .

2. ** n = 1 :**
   - Por definición,  L^1 = L = λ .

3. ** n = 2 :**
   - Concatenamos cada elemento de  L^1  consigo mismo:  
      L^2 = λ·λ = λ.

4. ** n = 3 :**
   - Concatenamos cada elemento de  L^2  con cada elemento de  L^1 :  
      L^3 = λ·λ·λ = λ.

### **Generalización para un  n  arbitrario**
Para cualquier valor de  n ≥ 0 , la concatenación de cadenas en el lenguaje  L = λ  siempre produce el mismo resultado:  
 
L^n = λ.
 

Esto ocurre porque la concatenación de la palabra vacía ( λ ) con cualquier cadena siempre resulta en la palabra vacía.

### **Conclusión**
- Para cualquier  n ≥ 0, L^n = λ. \
