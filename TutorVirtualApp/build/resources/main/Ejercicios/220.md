# Problema: Simulación de un AFN para las cadenas dadas.  

## Enunciado:  
Compruébese si reconocen o no las cadenas que se indican en cada caso, mostrando las transiciones que se van produciendo paso a paso.  

### Tabla de transiciones del AFN:  

| Estado | Entrada 'a'      | Entrada 'b'      | Entrada 'c'      | Entrada 'ε'    |  
|--------|------------------|------------------|------------------|----------------|  
| q0     | {q1}            | {q2, q3}        | ∅                | {q2}           |  
| q1     | ∅                | {q3, q4}        | {q1, q3}         | ∅              |  
| q2     | {q3}            | {q1, q2}        | ∅                | ∅              |  
| q3     | ∅                | {q0}            | {q2}             | ∅              |  
| q4     | ∅                | {q2, q3}        | {q0, q1, q4}     | {q1, q2}       |  

Cadenas a analizar:  
- x = aabc 
- y = bbacab  
- z = bacaabc  

---

## Simulación paso a paso para cada cadena:  

#### 1. Cadena x = aabc:  
Transiciones realizadas:  
- (q_0, 'a') → q_1.  
- Desde q_1: (q_1, 'a') no tiene transición válida.  
- Desde q_1: (q_1, 'b') → q_3, q_4. Desde q_3: no hay transición válida con 'c'. Desde q_4: no hay transición válida con 'c'.  

Estado final alcanzado: **No se alcanza un estado final**.  
Resultado: **No reconocida**.  

#### 2. Cadena y = bbacab:  
Transiciones realizadas:  
- Desde q_0: (q_0, 'b') → q_2, q3. Desde q_2: (q_2, 'b') → q_1, q_2. Desde q_1: no hay transición válida con 'a'.  

Estado final alcanzado: **No se alcanza un estado final**.  
Resultado: **No reconocida**.  

#### 3. Cadena z = bacaabc:  
Transiciones realizadas:
- Desde q_0: (q_0, 'b') → q_2, q3. Desde q_2: no hay transición válida con 'a'. Desde q_3: no hay transición válida con 'a'.  

Estado final alcanzado: **No se alcanza un estado final**.  
Resultado: **No reconocida**.  

---

## Conclusión:  

Resultados para cada cadena:
- x = aabc: **Rechazada**.  
- y = bbacab: **Rechazada**.  
- z = bacaabc: **Rechazada**.
