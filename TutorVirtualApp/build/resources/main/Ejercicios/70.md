# Problema: Construcción de una gramática en Forma Normal de Greibach (FNG) para un lenguaje L

## Enunciado
Diseñar una gramática en Forma Normal de Greibach (FNG) que genere el lenguaje:
L = { a^n b^m | m ≥ n, n ≥ 1 }.

---

## Solución

### Paso 1: Análisis del lenguaje
El lenguaje L está formado por cadenas que:
1. Comienzan con al menos un "a" (n ≥ 1).
2. Contienen al menos tantos "b" como "a" (m ≥ n).

Ejemplos de cadenas en L:
- ab, aab, aabb, aaabbb, abbb, ...

### Paso 2: Requisitos de la Forma Normal de Greibach (FNG)
Una gramática está en FNG si todas las reglas tienen la forma:
A → aα,
donde:
- A es un no terminal.
- a es un símbolo terminal.
- α es una cadena (posiblemente vacía) de no terminales.

---

### Paso 3: Construcción de la gramática

#### Símbolos no terminales:
- S: Símbolo inicial.
- A, B: No terminales auxiliares.

#### Producciones en FNG:
1. Para garantizar al menos un "a":
   - S → aA.

2. Para generar más "a" o cambiar a la generación de "b":
   - A → aA (añadir más "a").
   - A → bB (cambiar a la generación de "b").

3. Para generar más "b":
   - B → bB (añadir más "b").
   - B → b (terminar con un único "b").

---

### Gramática en FNG
La gramática resultante es:
S → aA
A → aA | bB
B → bB | b

---

### Paso 4: Validación

#### Ejemplo de derivaciones:
1. Para la cadena "aabbb":
   - Derivación:
     S → aA → aaA → aabB → aabbB → aabbb.

2. Para la cadena "abb":
   - Derivación:
     S → aA → abB → abbB → abb.

#### Propiedades del lenguaje generado:
- Todas las cadenas comienzan con al menos un "a", garantizado por la regla inicial (S → aA).
- La cantidad de "b" siempre es mayor o igual que la cantidad de "a", garantizado por las reglas de transición (A → bB, B → bB | b).

---

### Conclusión
La gramática en Forma Normal de Greibach (FNG) que genera el lenguaje dado es:

S → aA
A → aA | bB
B → bB | b

Esta gramática cumple con las restricciones de la FNG y genera exactamente las cadenas del lenguaje caracterizado por:
L = { a^n b^m | m ≥ n, n ≥ 1 }.
