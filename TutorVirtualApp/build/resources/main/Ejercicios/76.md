# Problema: Determinar si L es un lenguaje independiente de contexto (LIC)

## Enunciado
Determinar si el lenguaje L = { w·w | w es una cadena formada por a's y b's } es un lenguaje independiente de contexto (LIC). Justifique su respuesta.

---

## Solución

### Paso 1: Definición del lenguaje
El lenguaje L está formado por cadenas de la forma w·w, donde w es una cadena arbitraria compuesta de los símbolos a y b. Ejemplos de cadenas en L:
- Si w = a: la cadena es aa.
- Si w = ab: la cadena es abab.
- Si w = baa: la cadena es baabaa.

Formalmente, el lenguaje puede expresarse como:
L = { xx | x ∈ {a, b}* }.

---

### Paso 2: Propiedades de los lenguajes independientes de contexto (LIC)
Un lenguaje independiente de contexto puede ser generado por una gramática libre de contexto (GIC) o reconocido por un autómata con pila (PDA). Sin embargo, los lenguajes independientes de contexto tienen limitaciones en cuanto a la cantidad de memoria que pueden usar, ya que los PDA solo pueden contar una cantidad finita de elementos.

Para verificar si L es un LIC, debemos analizar si existe una gramática libre de contexto que pueda generar todas las cadenas en L.

---

### Paso 3: Argumento basado en el bombeo para lenguajes independientes de contexto
El lema del bombeo para lenguajes independientes de contexto establece que, si un lenguaje es independiente de contexto, entonces cualquier cadena suficientemente larga en el lenguaje puede dividirse en cinco partes (uvwxy) tal que:
1. vwx tiene una longitud máxima limitada (|vwx| ≤ p, donde p es la constante del lema).
2. vx ≠ λ (al menos uno entre v o x no está vacío).
3. Para cualquier número i ≥ 0, la cadena resultante uv^iwx^iy también pertenece al lenguaje.

#### Aplicación del lema del bombeo:
Supongamos que L = { xx | x ∈ {a, b}* } es un LIC. Tomemos una cadena suficientemente larga en el lenguaje, por ejemplo:
z = a^p b^p a^p b^p,
donde p > 0.

Dividimos z = uvwxy, cumpliendo las condiciones del lema:
1. El segmento central (vwx) tiene longitud máxima limitada (|vwx| ≤ p).
2. Al menos uno entre v o x no está vacío.

Si bombeamos (i ≠ 1), la estructura simétrica de la cadena se rompe porque el número de símbolos en las dos mitades ya no coincide. Por ejemplo:
- Si bombeamos hacia arriba (i = 2), obtenemos una cadena como:
  uv^2wx^2y = a^{p+k}b^p a^p b^{p+k},
  que no pertenece al lenguaje porque las dos mitades ya no son iguales.
- Si bombeamos hacia abajo (i = 0), obtenemos una cadena como:
  uwy = a^{p-k}b^p a^p b^{p-k},
  que tampoco pertenece al lenguaje por la misma razón.

Por lo tanto, el lema del bombeo demuestra que L no puede ser un LIC.

---

### Paso 4: Conclusión
El lenguaje L = { w·w | w ∈ {a, b}* } no es un lenguaje independiente de contexto. Esto se debe a que los lenguajes independientes de contexto no pueden garantizar la igualdad exacta entre dos mitades arbitrariamente largas de una cadena, como lo requiere este lenguaje.
