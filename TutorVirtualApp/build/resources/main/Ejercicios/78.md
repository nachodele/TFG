# Problema: Determinar si una cadena pertenece al lenguaje generado por la gramática  G  utilizando el algoritmo CYK

##  Enunciado:
Dada la gramática G:
S → AB | AC | Sbc  
A → BC | a  
B → AC | b  
C → AB | cA  

Determine, aplicando el algoritmo CYK, si la cadena x = acacb pertenece al lenguaje  L(G) .

---

## Solución

### Paso 1: Conversión a Forma Normal de Chomsky (FNC)
Para aplicar el algoritmo CYK, la gramática debe estar en FNC. Las reglas ya cumplen con las restricciones de FNC:
1. Todas las producciones son del tipo A → BC o A → a.
2. No se requiere conversión adicional.

---

### Paso 2: Aplicación del algoritmo CYK
La cadena dada es w = acacb, de longitud n = 5. Construimos una tabla triangular donde cada celda contiene los no terminales que generan las subcadenas correspondientes.

#### Inicialización (subcadenas de longitud 1):
Para cada símbolo terminal en la cadena, identificamos los no terminales que lo generan:

Posición | Carácter | No terminales generadores  
1        | a        | A, C (por A → a, C → a)  
2        | c        | C (por C → cA)  
3        | a        | A, C (por A → a, C → a)  
4        | c        | C (por C → cA)  
5        | b        | B (por B → b)  

---

#### Subcadenas de longitud mayor a 1:

**Subcadenas de longitud 2:**  
1. Subcadena [1,2] ("ac"):  
   - Combinaciones posibles:  
     Primera parte (a = A, C), segunda parte (c = C).  
   - Reglas aplicables:  
     S → AC, B → AC, C → AB.  
   - Resultado: S, B, C.  

2. Subcadena [2,3] ("ca"):  
   - Combinaciones posibles:  
     Primera parte (c = C), segunda parte (a = A, C).  
   - Reglas aplicables:  
     S → AC, B → AC, C → AB.  
   - Resultado: S, B, C.  

3. Subcadena [3,4] ("ac"):  
   - Combinaciones posibles:  
     Primera parte (a = A, C), segunda parte (c = C).  
   - Reglas aplicables:  
     S → AC, B → AC, C → AB.  
   - Resultado: S, B, C.  

4. Subcadena [4,5] ("cb"):  
   - Combinaciones posibles:  
     Primera parte (c = C), segunda parte (b = B).  
   - Reglas aplicables:  
     Ninguna regla válida.  
   - Resultado: Ninguno.  

---

**Subcadenas de longitud 3:**  
1. Subcadena [1,3] ("aca"):  
   - Combinaciones posibles: Primera parte (ac = S, B, C), segunda parte (a = A, C).  
   - Reglas aplicables: Ninguna regla válida.  
   - Resultado: Ninguno.  

2. Subcadena [2,4] ("cac"):  
   - Combinaciones posibles: Primera parte (ca = S, B, C), segunda parte (c = C).  
   - Reglas aplicables: Ninguna regla válida.  
   - Resultado: Ninguno.  

3. Subcadena [3,5] ("acb"):  
   - Combinaciones posibles: Primera parte (ac = S, B, C), segunda parte (b = B).  
   - Reglas aplicables: Ninguna regla válida.  
   - Resultado: Ninguno.  

---

**Subcadenas de longitud 4 y 5:**  
No se generan no terminales válidos para estas subcadenas debido a la falta de combinaciones válidas en las reglas.

---

### Conclusión
El símbolo inicial (S) no aparece en la celda correspondiente a toda la cadena ([1,n] = [1,5] = "acacb"). Por lo tanto:

**Respuesta:** La cadena w = acacb no pertenece al lenguaje generado por la gramática G.
