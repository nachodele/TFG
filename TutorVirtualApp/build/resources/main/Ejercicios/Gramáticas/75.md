# Problema: Limpieza y conversión a Forma Normal de Chomsky (FNC)

## Enunciado
Dada la gramática independiente de contexto (GIC):
S → ABaa | B | ab
A → BCa | Ac | aC
B → AAA | BbB | λ
C → CEa | ACb | B
D → ab | b
E → aEa | bFb
limpie la gramática y conviértala a Forma Normal de Chomsky (FNC).

---

## Solución

### Paso 1: Limpieza de la gramática
La limpieza de una gramática implica:
1. Eliminar símbolos no generativos.
2. Eliminar símbolos no accesibles.
3. Eliminar producciones vacías (λ).
4. Eliminar producciones unitarias.

#### 1. Eliminación de símbolos no generativos
Un símbolo es generativo si puede derivar cadenas terminales:
- D → ab | b: D es generativo.
- E → aEa | bFb: E no es generativo porque depende de sí mismo y no puede derivar cadenas terminales. Eliminamos E y todas las producciones que lo contienen.

Producciones actualizadas:
S → ABaa | B | ab
A → BCa | Ac | aC
B → AAA | BbB | λ
C → ACb | B
D → ab | b

#### 2. Eliminación de símbolos no accesibles
Un símbolo es accesible si puede ser alcanzado desde el símbolo inicial (S):
- Desde S → ABaa | B | ab: Los símbolos accesibles son S, A, B, C, D.
- Todos los símbolos restantes son accesibles.

No se eliminan más símbolos en este paso.

#### 3. Eliminación de producciones vacías (λ)
El único símbolo anulable es B → λ. Eliminamos las producciones vacías y ajustamos las reglas para incluir todas las combinaciones posibles sin los símbolos anulables:

1. Para S → ABaa | B | ab:
   - Si eliminamos B → λ, obtenemos:
     S → ABaa | aa | ab.

2. Para A → BCa | Ac | aC:
   - Si eliminamos B → λ, obtenemos:
     A → Ca | BCa | Ac | aC.

3. Para C → ACb | B:
   - Si eliminamos B → λ, obtenemos:
     C → ACb.

Producciones actualizadas:
S → ABaa | aa | ab
A → BCa | Ca | Ac | aC
B → AAA | BbB
C → ACb
D → ab | b

#### 4. Eliminación de reglas unitarias
Las reglas unitarias son aquellas donde un no terminal deriva directamente otro no terminal (A → B, C → D, ...). Aplicamos el algoritmo para eliminarlas:

1. Para S → B:
   - Sustituimos las producciones de B → AAA | BbB:
     S → ABaa | aa | ab | AAA | BbB.

2. Para otras reglas unitarias, no se aplican sustituciones adicionales.

Producciones actualizadas:
S → ABaa | aa | ab | AAA | BbB
A → BCa | Ca | Ac | aC
B → AAA | BbB
C → ACb
D → ab | b

---

### Paso 2: Conversión a Forma Normal de Chomsky (FNC)
La FNC requiere que todas las reglas tengan una de las siguientes formas:
1. A → BC, donde B, C son no terminales.
2. A → a, donde a es un símbolo terminal.

#### Introducción de nuevos no terminales para terminales
Definimos nuevos no terminales para cada terminal:
- X_a → a,
- X_b → b.

Sustituimos los terminales en las reglas originales por los nuevos no terminales.

#### Descomposición de reglas con más de dos símbolos
Las reglas con más de dos símbolos en el lado derecho se descomponen introduciendo nuevos no terminales auxiliares.

1. Para S → ABaa:
   - Introducimos un nuevo no terminal: 
     Y_1 → AB,
     Reescribimos: S → Y_1 X_a X_a.

2. Para A → BCa:
   - Introducimos un nuevo no terminal:
     Y_2 → BC,
     Reescribimos: A → Y_2 X_a.

3. Para otras reglas largas (AAA, etc.), aplicamos el mismo proceso.

---

### Gramática final en FNC

1. Símbolo inicial:  
   S

2. Producciones:  
   S → Y_1 X_a X_a | X_a X_a | X_a X_b | Y_3 | Y_4  
   A → Y_2 X_a | Y_5 | X_a C  
   B → Y_3 | Y_6  
   C → AC X_b  
   D → X_a X_b | X_b  
   Auxiliares:  
     Y_1 → AB, Y_2 → BC, Y_3 → AA, Y_4 → Bb, Y_5 → CA, Y_6 → BB  
   Terminales:  
     X_a → a, X_b → b

---

### Conclusión
La gramática ha sido limpiada y convertida a Forma Normal de Chomsky (FNC), cumpliendo con los requisitos estructurales y generando el mismo lenguaje que la gramática original.
