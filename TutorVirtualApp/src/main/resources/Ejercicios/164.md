# Problema: Regularidad de L′ tras anteponer una secuencia fija

## Enunciado:
Sea L un lenguaje regular del alfabeto {x, y, z}. Sea L′ = { xyz w | w ∈ L }, es decir, el lenguaje resultante de anteponer la secuencia "xyz" a cada cadena de L. ¿Es regular L′?

a) Sí, siempre  
b) Depende de L  

## Solución:
La respuesta correcta es **a) Sí, siempre**.

### Paso 1: Reconocimiento de lenguajes regulares
- Dado que L es un lenguaje regular, existe un autómata finito o una expresión regular que lo reconoce.
- La cadena fija "xyz" constituye un lenguaje finito (de hecho, un único elemento), y todo lenguaje finito es regular.

### Paso 2: Concatenación de lenguajes regulares
- El lenguaje L′ se define como la concatenación de { xyz } y L:
  
L′ = {xyz} · L

- Es una propiedad conocida que la concatenación de dos lenguajes regulares (en este caso, un lenguaje finito y L) es regular.

### Paso 3: Conclusión
Dado que tanto { xyz } como L son regulares, y la concatenación de lenguajes regulares es regular, L′ es siempre regular. Esto se cumple sin importar la naturaleza particular de L, siempre que L sea regular.

Por lo tanto, la respuesta es **a) Sí, siempre**.
