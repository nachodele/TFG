# Problema: Estudiar la afirmación "Hay tantos números pares como números enteros"

## Enunciado
Estudiar la afirmación "Hay tantos números pares como números enteros"

## Solución

### Paso 1: Definición de cardinalidad
En teoría de conjuntos, dos conjuntos tienen la misma cardinalidad si existe una función biyectiva (uno a uno y sobre) entre ellos. La afirmación sugiere que los conjuntos de números pares y números enteros tienen la misma cardinalidad.

- El conjunto de los números enteros se denota como Z = { ..., -2, -1, 0, 1, 2, ... }.
- El conjunto de los números pares se denota como P = { ..., -4, -2, 0, 2, 4, ... }.

Ambos conjuntos son infinitos y debemos determinar si tienen el mismo "tamaño" en términos de cardinalidad.

### Paso 2: Construcción de una función biyectiva
Para demostrar que Z y P tienen la misma cardinalidad, construiremos una función biyectiva f: Z → P. Definimos f(n) = 2n, donde n ∈ Z.

#### Propiedades de f(n) = 2n:
1. **Inyectividad**: Si f(n₁) = f(n₂), entonces 2n₁ = 2n₂. Dividiendo ambos lados entre 2, obtenemos n₁ = n₂. Por lo tanto, f es inyectiva.
2. **Sobreyectividad**: Para cualquier número par p ∈ P, existe un número entero n = p/2 ∈ Z tal que f(n) = p. Por lo tanto, f es sobreyectiva.

Dado que f es inyectiva y sobreyectiva, es una biyección entre Z y P.

### Paso 3: Interpretación del resultado
La existencia de una función biyectiva demuestra que los conjuntos Z y P tienen la misma cardinalidad. Esto significa que hay "tantos" números pares como números enteros, aunque intuitivamente pueda parecer que el conjunto de los números pares es "más pequeño" porque es un subconjunto propio de los enteros.

### Paso 4: Ejemplo de emparejamiento
Podemos construir explícitamente el emparejamiento entre los números enteros y los pares utilizando la función f(n) = 2n:

| Entero (Z) | Par (P) |
|------------|---------|
| -2         | -4      |
| -1         | -2      |
| 0          | 0       |
| 1          | 2       |
| 2          | 4       |

Cada número entero tiene un único número par asociado mediante esta función.

### Conclusión
Se ha demostrado formalmente que el conjunto de los números pares tiene la misma cardinalidad que el conjunto de los números enteros. Por lo tanto, la afirmación "Hay tantos números pares como números enteros" es **verdadera**.
