# Problema: Construcción de un Autómata Finito (AF) equivalente a una Expresión Regular.  

## Enunciado:  
Construir un Autómata Finito (AF) equivalente a la siguiente expresión regular:  
α = a · (ab + ba)* + ab*

## Solución:  
La solución consiste en diseñar un autómata finito que reconozca el lenguaje descrito por la expresión regular α. La construcción se realiza siguiendo los pasos de síntesis de Kleene, que garantizan la equivalencia entre expresiones regulares y autómatas finitos.  

### Paso 1: Análisis de la expresión regular  
1. **Descomposición**:  
- La expresión α tiene dos componentes principales separadas por una unión (+):  
  - a · (ab + ba)*: Representa cadenas que comienzan con a, seguidas por cualquier número de repeticiones del patrón ab o ba.  
  - ab*: Representa cadenas que comienzan con ab, seguidas por cualquier número de repeticiones de b. 

2. **Prioridades**:  
- La concatenación (·) tiene mayor prioridad que la unión (+).  
- La clausura de Kleene (*) aplica al conjunto ab + ba y al símbolo b en b*. 

### Paso 2: Construcción del autómata finito  
El autómata se construye considerando los estados necesarios para manejar cada componente de α.  

#### Estados y transiciones:  
- **Estados**: Se definen los estados necesarios para representar las transiciones entre los elementos de la expresión regular.  
- **Transiciones**: Cada transición corresponde a un símbolo del alfabeto (a, b) y conecta dos estados.  

El autómata resultante es el siguiente:  

| Estado | Entrada 'a' | Entrada 'b' |  
|--------|-------------|-------------|  
| q_0 | q_1      | -        |  
| q_1 | q_2      | q_3      |  
| q_2 | -        | q_3      |  
| q_3 | q_2      | q_4      |  
| q_4 | -        | q_4      |  

#### Descripción del autómata:  
- **Estado inicial**: q_0.  
- **Estados finales**: q_4.  
- **Transiciones clave**:
  - Desde el estado inicial (q_0), una entrada 'a' lleva al estado intermedio (q_1).  
  - El ciclo entre los estados q_2 \→ q_3 maneja las repeticiones del patrón (ab + ba)*.  
  - Las transiciones hacia el estado final (q_4) permiten procesar las cadenas terminadas en b^*.  

### Paso 3: Validación del diseño  
El autómata reconoce todas las cadenas generadas por la expresión regular α = a · (ab + ba)* + ab*, cumpliendo con las reglas establecidas para lenguajes regulares.
