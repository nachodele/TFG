# Problema: Construcción de gramáticas regulares equivalentes a expresiones regulares

## Enunciado
Construya una gramática regular (GR) equivalente a las siguientes expresiones regulares:

1.  α = a · (a + b)^* + b^*   
2.  β = 10^*1(01^* + 1^*0)^*   
3.  δ = (a + b)^* · a + b^* 

## Solución

### Gramática para  α = a · (a + b)^* + b^* 
#### Descomposición:
1.  a · (a + b)^* : Cadenas que comienzan con  a , seguidas por cualquier combinación de  a 's y  b 's.
2.  b^* : Cadenas formadas por cero o más repeticiones de  b .

#### Gramática Regular:
- Símbolos no terminales:  S, A, B, C 
- Reglas:
  -  S → aA | B 
  -  A → aA | bA | λ 
  -  B → bB | λ 

Esta gramática genera el lenguaje descrito por  α .

---

### Gramática para  β = 10^*1(01^* + 1^*0)^* 
#### Descomposición:
1.  10^*1 : Cadenas que comienzan con un  1 , seguidas por cero o más  0 's y terminan con un  1 .
2.  (01^* + 1^*0)^* : Cero o más repeticiones de subcadenas del tipo:
   - Un  0  seguido por cero o más  1 's, o
   - Un  1  seguido por cero o más  0 's.

#### Gramática Regular:
- Símbolos no terminales:  S, A, B, C, D, E 
- Reglas:
  -  S → 1A1B | λ 
  -  A → 0A | λ 
  -  B → C | λ 
  -  C → 0D | D0C | λ 
  -  D → 1D | λ 

Esta gramática genera el lenguaje descrito por  β .

---

### Gramática para  delta = (a + b)^* · a + b^* 
#### Descomposición:
1. ** (a + b)^* · a:**  
   Este término genera cadenas que contienen cualquier combinación de  a's y  b's seguidas por un único símbolo terminal adicional ( a).
2. ** b^*:**  
   Este término genera cadenas formadas únicamente por cero o más repeticiones de  b.

#### Gramática Regular:
- Símbolos no terminales:  S, A, C, D
- Reglas:
  - Para la parte  (a + b)^* · a:
    -  S → A | D
    -  A → aA | bA | C
    -  C → a (finaliza con un único símbolo terminal adicional).
  - Para la parte  b^*:
    -  D → bD | λ

#### Gramática completa:
- Símbolos no terminales:  S, A, C, D
- Reglas finales:
  -  S → A | D
  -  A → aA | bA | C
  -  C → a
  -  D → bD | λ

Esta gramática genera el lenguaje descrito por la expresión regular  delta = (a + b)^* · a + b^* .

---

## Conclusión
Se han construido gramáticas regulares equivalentes para las expresiones regulares dadas:

1. Para  α = a · (a + b)^* + b^* :
   - Gramática con las reglas:  
     -  S → aA | B, A → aA | bA | λ, B → bB | λ. 

2. Para  β = 10^*1(01^* + 1^*0)^* :
   - Gramática con las reglas:  
     -  S → 1A1B | λ, A → 0A | λ, B → C | λ, C → 0D | D0C | λ, D → 1D | λ. 

3. Para  delta = (a + b)^* · a + b^* :
   - Gramática con las reglas:  
     -  S → A | D, A → aA | bA | C, C → a, D → bD | λ.
