# Problema: Determinar si una cadena pertenece al lenguaje generado por la gramática  G  utilizando el algoritmo CYK

## Enunciado
Dada la gramática  G  en Forma Normal de Chomsky (FNC):
-  S → AB | AC | BC 
-  A → BA | a 
-  B → AC | b 
-  C → AB | cA 

Determinar, utilizando el algoritmo CYK, si la cadena w = bcaab pertenece al lenguaje generado por  G .



## Solución

### Paso 1: Aplicación del algoritmo CYK
La cadena dada es w = bcaab, de longitud n = 5. Construimos una tabla triangular donde cada celda contiene los no terminales que generan las subcadenas correspondientes.

#### Inicialización (subcadenas de longitud 1):
Para cada símbolo terminal en la cadena, identificamos los no terminales que lo generan:

Posición | Carácter | No terminales generadores  
1        | b        | B (por B → b)  
2        | c        | C (por C → cA)  
3        | a        | A (por A → a)  
4        | a        | A (por A → a)  
5        | b        | B (por B → b)  

---

#### Subcadenas de longitud mayor a 1:

**Subcadenas de longitud 2:**  
1. Subcadena [1,2] ("bc"):  
   - Combinaciones posibles: Primera parte (b = B), segunda parte (c = C).  
   - Reglas aplicables: S → BC.  
   - Resultado: S.  

2. Subcadena [2,3] ("ca"):  
   - Combinaciones posibles: Primera parte (c = C), segunda parte (a = A).  
   - Reglas aplicables: C → AB.  
   - Resultado: C.  

3. Subcadena [3,4] ("aa"):  
   - Combinaciones posibles: Primera parte (a = A), segunda parte (a = A).  
   - Reglas aplicables: Ninguna regla válida.  
   - Resultado: Ninguno.  

4. Subcadena [4,5] ("ab"):  
   - Combinaciones posibles: Primera parte (a = A), segunda parte (b = B).  
   - Reglas aplicables: S → AB, C → AB.  
   - Resultado: S, C.  

---

**Subcadenas de longitud 3:**  
1. Subcadena [1,3] ("bca"):  
   - Combinaciones posibles: Primera parte (bc = S), segunda parte (a = A).  
   - Reglas aplicables: S → SA, C → SA.  
   - Resultado: Ninguno.  

2. Subcadena [2,4] ("caa"):  
   - Combinaciones posibles: Primera parte (ca = C), segunda parte (a = A).  
   - Reglas aplicables: Ninguna regla válida.  
   - Resultado: Ninguno.  

3. Subcadena [3,5] ("aab"):  
   - Combinaciones posibles: Primera parte (aa = Ninguno), segunda parte (b = B).  
   - Reglas aplicables: Ninguna regla válida.  
   - Resultado: Ninguno.

**Subcadenas de longitud 4:**  
1. Subcadena [1,4] ("bcaa"):  
   - Combinaciones posibles: Primera parte (bc = S), segunda parte (aa = Ninguno).  
   - Reglas aplicables: Ninguna regla válida.  
   - Resultado: Ninguno.

   - Combinaciones posibles: Primera parte (ca = C), segunda parte (ab = S, C).

**Subcadena de longitud 5:**  
Subcadena [1,5] ("bcaab"):  
- Combinaciones posibles: Primera parte (bcaa = Ninguno), segunda parte (b = B).  
- Reglas aplicables: Ninguna regla válida.  
- Resultado: Ninguno.

### Conclusión
El símbolo inicial (S) no aparece en la celda correspondiente a toda la cadena ([1,n] = [1,5] = "bcaab"). Por lo tanto:

**Respuesta:** La cadena w = bcaab no pertenece al lenguaje generado por la gramática G.
