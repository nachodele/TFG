# Problema: Operaciones sobre un lenguaje

## Enunciado:
Sea A ⊆ Σ^*. Estudie el resultado de las siguientes operaciones sobre  L :
1.  (L^+)^n  ∀ n ∈ ℕ
2.  (L^+)^+ 
3.  (L^*)^* 

## Solución:
### **Definiciones previas**
1. **Clausura positiva ( L^+ )**: Es el conjunto de todas las cadenas que se pueden formar concatenando una o más veces cadenas de  L . Formalmente:
   L⁺ = ⋃_{i=1}^∞ Lⁱ  
   donde Lⁱ = L · L · ... · L (i veces).

2. **Clausura de Kleene ( L^* )**: Es el conjunto de todas las cadenas que se pueden formar concatenando cero o más veces cadenas de  L . Formalmente:
   L* = ⋃_{i=0}^∞ Lⁱ

3. **Potencia de un lenguaje ( L^n )**: Es la concatenación del lenguaje consigo mismo  n -veces. Formalmente:
   -  L^0 = { λ } , donde  λ  es la palabra vacía.
   -  L^n = L^{n-1} · L, n > 0.

### **Análisis de las operaciones**
#### 1. ** (L^+)^n,\, n ∈ ℕ **
   - El operador  (L^+)^n  indica la concatenación del lenguaje  L^+  consigo mismo  n -veces.
   - Dado que  L^+ = L^{≥1} = L¹ ⋃ L² ⋃ ..., al concatenar  n -veces, el resultado es equivalente a todas las posibles concatenaciones de cadenas de  L^+  con longitud mínima igual a  n .
   - Formalmente:
     (L⁺)ⁿ = (L^{≥1})ⁿ = L^{≥n}  
     Esto significa que el resultado es el conjunto de todas las cadenas obtenidas concatenando al menos  n  palabras de  L .

#### 2. ** (L^+)^+ = (L^{≥1})^+ = L^{≥1} = L^+ **
   - La clausura positiva aplicada sobre otra clausura positiva no agrega nuevos elementos al lenguaje resultante.
   - Esto ocurre porque:
     - La operación (L^{≥1})⁺ = (L^{≥1})^{≥1} = L^{≥1} = L⁺.
   - Por lo tanto:
     - El resultado es simplemente el lenguaje original bajo clausura positiva.

#### 3. ** (L^*)^* = (L^{≥0})^{≥0} = L^{≥0} = L^* **
   - Similar al caso anterior, la clausura de Kleene aplicada sobre otra clausura de Kleene no genera nuevos elementos.
   - Esto ocurre porque:
     - La operación incluye todas las posibles combinaciones de palabras en  L^{≥0} = L^*.
     - Por definición, ya están incluidas en el primer cierre.
   - Por lo tanto:
     - El resultado es simplemente el lenguaje original bajo clausura de Kleene.

### **Conclusión**
- ** (L⁺)ⁿ = L^{≥n}.**  
- ** (L⁺)⁺ = L⁺.**  
- ** (L*)* = L*.**
