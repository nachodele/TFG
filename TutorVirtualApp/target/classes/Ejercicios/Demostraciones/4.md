# Problema: Demostrar que (A • B)^-1 = B^-1 • A^-1

## Enunciado
Sean A y B lenguajes definidos sobre un mismo alfabeto. Probar que el inverso de la concatenación de A y B es igual a la concatenación del inverso de B con el inverso de A, es decir:

(A • B)^-1 = B^-1 • A^-1.

## Solución

### Paso 1: Definición de las operaciones
- **Concatenación de lenguajes**: La concatenación de dos lenguajes A y B, denotada como A • B, contiene todas las cadenas que se pueden formar concatenando una cadena de A con una cadena de B:
  A • B = {xy : x ∈ A, y ∈ B}.

- **Inverso de un lenguaje**: El inverso de un lenguaje X, denotado como X^-1, contiene todas las cadenas que se obtienen invirtiendo las cadenas de X:
  X^-1 = {w^R : w ∈ X}, donde w^R es la reversa de la cadena w.

### Paso 2: Lado izquierdo de la igualdad ((A • B)^-1)
Por definición del inverso, el inverso del lenguaje A • B es:
(A • B)^-1 = {w^R : w ∈ (A • B)}.

Dado que w ∈ (A • B), esto significa que w puede expresarse como la concatenación de dos cadenas x e y, donde x ∈ A e y ∈ B. Por lo tanto:
(A • B)^-1 = {(xy)^R : x ∈ A, y ∈ B}.

Sabemos que la reversa de una concatenación es la concatenación de las reversas en orden inverso:
(xy)^R = y^R • x^R.

Sustituyendo esto en la expresión anterior:
(A • B)^-1 = {y^R • x^R : x ∈ A, y ∈ B}.

### Paso 3: Lado derecho de la igualdad (B^-1 • A^-1)
Por definición del inverso y la concatenación, el lado derecho es:
B^-1 • A^-1 = {y^R : y ∈ B} • {x^R : x ∈ A}.

Esto significa que contiene todas las cadenas que se pueden formar concatenando una cadena del inverso de B con una cadena del inverso de A:
B^-1 • A^-1 = {y^R • x^R : y ∈ B, x ∈ A}.

### Paso 4: Comparación entre ambos lados
Observamos que ambas expresiones son equivalentes:
- Lado izquierdo: (A • B)^-1 = {y^R • x^R : x ∈ A, y ∈ B}.
- Lado derecho: B^-1 • A^-1 = {y^R • x^R : y ∈ B, x ∈ A}.

Dado que el orden en el que se toman los elementos no afecta el resultado final, se cumple que:
(A • B)^-1 = B^-1 • A^-1.

### Conclusión
Se ha demostrado que el inverso de la concatenación de dos lenguajes es igual a la concatenación del inverso del segundo lenguaje con el inverso del primero.
